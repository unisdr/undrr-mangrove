# Brand analyst review and second iteration

Review requested by the user on 3 October 2026. A dedicated brand analyst
subagent reviewed the Mangrove field guide against the DELTA brand book,
lookbook contact sheets, public-source inventory, production notes and editorial
review. This is a design critique, not approval from UNDRR Communications.

The central finding: the first version borrowed DELTA’s reading interface more
than its application method. It was primarily a foundations and token reference.
DELTA’s stronger contribution is showing identity at work across different
surfaces, with clear purpose, composition and institutional ownership.

| Before                                          | Change in this iteration                                                                                                              |
| ----------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------- |
| Foundations followed identity                   | An applications chapter immediately follows identity; technical reference stays later                                                 |
| Mostly uniform specimen framing                 | One message adapted to a 1.91:1 social card, web landing page, A4 cover/interior and 16:9 learning slide                              |
| Abstract visual examples                        | A new community risk-mapping scene anchors all four applications and the imagery chapter                                              |
| Photography advice without demonstration        | A visible image/caption composition explains people’s agency, contextual imagery, protected text and attribution                      |
| Theme tint could read as a property masthead    | Property names are text labels; existing UNDRR artwork appears separately as the ownership signature                                  |
| Token names explained visual decisions          | Each application describes audience intent, hierarchy and ownership before implementation details                                     |
| Generic editorial shell dominated               | Roboto Condensed carries display headlines; application headings make room for the compositions                                       |
| Reference provenance stayed in repository notes | Visible concept labels and an expandable reference note distinguish new compositions from public references and DELTA’s internal work |

## Specific inspiration

- `delta-pw/_docs/brand/lookbook/mockups/13-link-card.jpg`: the sequence of a
  solid message panel, image and protected white signature area.
- `mockups/11-undrr-page.jpg` and `10-country-site-laptop.jpg`: a clear hierarchy
  from institutional ownership to hero content and onward action.
- `mockups/07-report-cover.jpg` and `08-report-spread.jpg`: an expressive cover
  beside a quieter reading surface, rather than identical cards.
- `mockups/14-training-slide.jpg`: a learning question, practical steps and a
  restrained footer signature.
- `refs/conventions.md`: mostly white surfaces, generous title margins,
  purpose-specific formats and a thin Sendai rule.
- `editorial-review/review.md`: the corrective finding that nine of fifteen
  DELTA concepts were event scenes, with no field work. The Mangrove iteration
  emphasizes community knowledge and prevention.

All DELTA reference captures are marked internal by `refs/conventions.md`.
They were inspected for composition, not copied into this project. Public
originals are linked from the application chapter using `refs/sources.csv`.
No exploratory DELTA logo or invented partner artwork is used.

## Follow-up review

The analyst inspected all four rendered compositions and found no fundamental
brand or composition blocker. The focused refinements were: reduce opening
title/spacing, preserve concept labels within each actual application, describe
the scene in alt text, remove first person from the learning copy and preserve
a complete participant in its narrow photo crop. Those refinements are applied.

## Boundaries

The layouts demonstrate communications composed with Mangrove foundations.
They are not a newly approved print/social identity or replicas of each
production property’s masthead. The theme selector compares colour layers.
The property text is a label, not substitute logo artwork. Existing UNDRR
artwork remains unmodified in a white signature area.

The image is a new AI-generated fictional scene. It is not a record of a real
event or place and has no claimed photographer attribution. The image,
generation tool and complete prompt are documented in [assets/README.md](assets/README.md).

The four formats demonstrate different reading and viewing conditions. On
small screens the social composition reflows to 4:5 and the report spread stacks.
The print view includes the selected application format, with its annotations.

## Further opportunities

- Use approved, correctly credited documentary photographs for a maintained
  public guide.
- Add actual property artwork through existing theme metadata when available.
- Test applications against the communications team’s print and social templates.
- Expand around demonstrated audience needs, with a balanced range of community,
  prevention and recovery subjects.
