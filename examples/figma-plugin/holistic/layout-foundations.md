This source-only cohort projects three genuine authored module contracts into 28 finite specimens: `layout-container` (8), `layout-grid-specimen` (4), and `full-width-background` (16). Each records English or Arabic root routing and source viewport 390 or 1164. The actual story copy remains English in both root contexts. These modules are exported from their local modules, but are absent from the package entry point. This does not introduce new public package exports.

Short, supported TEXT property edits are checked on their actual owning consumer instance. They do not demonstrate arbitrary reflow beyond the captured allocation. The native fixture recognizes only the finite emitted candidate SVGs; it is an offline setup adapter, not evidence that SVG import or raster rendering passed in Figma.

## Verification and open gates

The dedicated harness checks native-compatible variable scopes and every import error before the actual builder. Across all five modes it checks owning dimensions, signed offsets, padding, paints, opacity, text defaults, wrap policy and source property references, and exercises supported owning consumer edits through two nonempty zero-create repeat snapshots. Source-artifact drift, wrong helper identity/type, style-kind/font shape, foundation drift and missing required fonts must fail without publishing caller changes or creating permanent scene assets.

This is source-only evidence. Native font loading/axes/bytes, glyph and bidi rendering, native source positions and pixels, SVG cadence/raster, actual responsive or edited-content reflow, variable-mode switching, consumer/library publication, novice handoff and reduced maintenance merge acceptance remain separate gates. Container/Grid/FullWidth scene counts do not establish full component or page completeness.
