# Source Gallery cohort

Gallery is one actual source component with fourteen authored configurations. It renders an inline main media viewport, descriptions and thumbnails. The implementation has no lightbox branch; the introductory wording in the SCSS and documentation does not create one.

The first image cohort covers genuine selected first/interior/last photos, landscape/portrait/square/panorama containment, many-image thumbnail scrolling allocation, left/bottom thumbnails, omitted thumbnails/arrows/descriptions, minimal configuration, starting at the second item, a loop endpoint and corner controls at 390/1164 across all five brands. WithCallback supplies behavior provenance without a different initial drawing. The real ‹/› controls use text, source circle/pill geometry and source disabled opacity; generic Button or icon substitutions are inappropriate.

Authored Picsum inputs are random redirect endpoints. Actual response bytes and the original-to-resolved request chain are pinned as an explicit deterministic media-response fixture shared by source measurements and recipes. Owning component code, CSS, title/caption strings and real selected-state interactions remain source-owned. The deterministic media fixture remaps IMG src and sets loading=eager to settle every pinned image, including offscreen thumbnails. This input fixture does not measure original lazy-loading behavior. Original pre-eager captures are preserved separately; shared recorded geometry, styles, text and scroll fields are compared before acceptance. This does not establish stable remote picture contents or metadata from those placeholder URLs.

Live video, embedded browsing, their loading states and UA controls need separate genuine source contracts. The two authored HTML branches and their 0.12 scaled inert thumbnail previews need explicit source context scaling, rather than full-size text in the thumbnail. No fake player, generic embed, blank media or guessed HTML pattern is accepted as a substitute. Empty media has no authored visible fallback in the current implementation.

Source image pixels, native contain/cover, glyphs, focus, reflow, behavior, locale/RTL, scrolling, ordinary plugin execution and publication remain independent gates. The bounded `gallery-image` source candidate contains 44 finite variants and 220 actual settled source captures. It covers eleven authored configurations plus 767/768 breakpoint draws of BasicGallery. WithCallback has equal initial image anatomy and remains behavioral provenance; MixedMedia and WithHtmlContent are separate remaining cohorts. This is a partial Gallery family, not complete Gallery acceptance.

The recipe preserves the exact captured IMG owner box. For `object-fit:contain`, it derives a centered inner drawing with the minimum uniform scale from the pinned JPEG natural dimensions and uses the existing image FILL primitive on that natural-aspect leaf. This does not use an unsupported native FIT paint or crop the entire owner. For example, a 358 by 119.328125 panorama owner contains a 357.984375 by 119.328125 drawing at x 0.0078125. Cover thumbnails use the source owner and FILL. Source zero padding/border and centered untransformed image assumptions are guarded. Native image raster remains unverified.

Whole logical Title and Caption use their source owning capacities and stable authored configuration, selected index and viewport property names. Their anatomy IDs do not depend on copy. Unicode arrows remain source glyph candidates without editable public labels. All five brands use source font-family and font-size aliases, source paint roles and CSS opacity converted to the builder's percentage units. The offline actual-builder harness checks source allocations, contain formula, cover paints, both editable consumer fields, cached JPEG bytes, exact recorded repeat geometry and two zero-create rebuilds. A modeled native shared-default fixture also deliberately reproduces corruption with the old generic Title name. This is an offline ownership test, not native consumer proof.

Source and evidence byte guards pin the owning JSX/SCSS/stories, generated stylesheet, active bundled fonts and licences, captured foundation values, all 24 actual JPEG responses, the replay/capture scripts and all 220 archived scene records. Caller type/style-kind collisions, malformed implicit font shapes and source drift refuse without replacing caller arrays. Missing required fonts refuse before scene, style and image writes. Original 171 settled pre-eager records are retained outside the repository; their scoped geometry/style/text/scroll fields equal the corresponding eager replay records in the archived comparison. Neither comparison establishes original lazy-loading behavior or raster equality.
