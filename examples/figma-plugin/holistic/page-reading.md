## TOC anatomy and marker contract

The authored pages use unnumbered lists. Reusing the normal numbered six-link recipe would change their source content and markers. Both source page rail TOCs are 256px at the desktop preset. At 390px the default UNDRR theme produces report350/article330px; the other four captured themes produce report370/article350px, reflecting the observed source Storybook cascade.

The source TOC has a 2px neutral300 left border and 20px inside padding. Its title is Roboto Bold18px at110% line height, with10px separation from the list. The list adds20px indentation. Each li adds2.5px left padding; the link adds2.5px block padding around16px/24px Regular text, producing a29px authored row. Adjacent source5px li margins collapse into5px gaps. All emitted source labels fit one line.

The actual UA marker is a circular disc. A temporary browser-only diagnostic changed `::marker` to explicit U+2022 with a trailing space. The original and diagnostic crops differed in both size and position: the source UA disc occupied about five raster pixels, whereas the Roboto bullet glyph was smaller and differently placed. The originals, crops and diagnostic result are preserved outside the repository. No typed-bullet substitute is emitted.

Each native marker is an ELLIPSE with a declared ideal5.333px diameter and measured candidate placement, x=-17.333px/y=10.833px relative to its source row. Those vector bounds are a finite projection of the observed Chromium circle and baseline. The raster pixel count is not authored CSS vector geometry, and this does not establish native pixel equality or other browser markers. Source font-size16 is guarded; a font or marker change requires fresh evidence. Arbitrary multiline labels, counts and unbroken overflow are outside this contract.

Links retain their source anchor IDs in metadata. Their native text is underlined with the source15percent underline offset and interactive color. They are not assigned invented HTTPS targets for internal page anchors. Scrollspy, smooth scrolling, history, focus, hover, semantic HTML and keyboard navigation remain browser/native interaction gates. Hydration's extra empty list is omitted because it has no visible geometry; no semantic DOM equivalence is claimed.

## Quote anatomy and context

The source line treatment is a clipped rounded surface with a0/4/12px black8percent shadow, content padding50px at the narrow preset and60px at the desktop preset, a padded blockquote, a100x4px separator, and optional author/title. Source external bottom margin50px standalone or30px in the article is recorded as metadata and excluded from the native root footprint.

Standalone quotes use Roboto Bold Italic18px at150% line height. The article's `mg-content blockquote` cascade instead uses32px at116% below the medium boundary and40px at115% above it. Standalone blockquote bottom margin30px is represented explicitly; the article cascade removes it. The separator retains10px top and20px bottom allocation, followed by the author's10px top margin. The author requests weight600 at16px/24px; the title is12.5px with inherited24px line height and5px top separation. This inherited title line height is not12.5 times1.5.

The opening quotation mark remains editable native TEXT containing U+201C. It uses actual Roboto Bold Italic48px and a19.125px observed source advance. Its source offset is x0/y-10. Fixed native line-box height is72px standalone,55.68px narrow article, and55.2px desktop article. The source renderer quantizes the latter two to55.671875/55.1875px; the recipe preserves the ideal CSS line heights and keeps native font/paint baseline comparison open. The shared bounded START/START absolute primitive preserves this decoration outside the quote's flow; no glyph outline substitute is used.

Light uses blue900 at10percent for the surface,90percent for the quote,70percent for the separator and50percent for the opening mark. The mark also has source node opacity50percent, yielding25percent combined alpha. Dark uses opaque blue900 and white text, with the mark at80percent paint alpha times50percent opacity. Bright uses white, a1px neutral200 border, neutral900 quote, neutral500 mark at50percent opacity, and a70percent blue900 separator. All role values derive across the five source brands. The opacity FLOAT is50 because the builder's native opacity binding convention is percentage values.

The rich bright composite preserves contiguous styled text runs and the real author URL. Source `em`/`cite` inside an already italic quote does not create a different visible style, so those adjacent equal signatures remain one run; the hard line break remains in that run. The emphasized attribution title has a distinct Italic run. Neither semantic citation nor browser sanitization is claimed as a Figma interaction. Current rich capability requires opaque paints: rich translucent light-quote content remains explicitly unsupported, with no opaque replacement.

## Verification and remaining gates

The actual-builder harness builds all sixteen variants in each of five brands. It checks source widths, link and disc counts, circle allocation, border/padding, editable native quotation mark font/dimensions/offset/opacity, and context-specific quote typography. Two ordinary mocked repeats create zero nodes and preserve exact recorded mocked geometry, identities, positioned consumer instances, edited plain properties, and formatted rich source/consumer edits. Source CSS/JS/fixture drift, foreign helper/style identities and missing exact Bold Italic refuse; missing-font refusal precedes canvas mutation.

The bounded source mocks do not rasterize text or establish native fonts, UA-disc pixels, alpha/shadow pixels, arbitrary wrapping or rich range defaults/inheritance. Image/portrait quotes, floats and RTL, source rich translucent paints, other browser markers, and native publication/consumer acceptance remain open. The canonical library, consumer and recovery checkpoint were not touched. Maintenance drift, deliberately changed style publication, composite publication, novice handoff and reduced merge acceptance remain separate gates.
