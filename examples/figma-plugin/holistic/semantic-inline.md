It returns an empty `families` array and `sourceRecipeReady:false`. These contracts are required work, not implemented components. No importer, builder lifecycle, zero-create or native acceptance is claimed.

The archive preserves actual HTML, logical owner copy, element styles, text atoms and client rectangles across five brands, three authored languages and two widths. The source module derives stable source-owner and span IDs, complete parent text and exact nonempty child UTF-16 ranges. It retains whole logical paragraphs and actual list items, rather than creating independently editable sentence fragments. All source inputs, archived evidence, capture drivers and fifteen actual font responses are pinned. The initial typography producer and its 31 files remain separate and unchanged.

## Capability work requested

Existing `mgRichText` supports mixed text style, fill, HTTPS link, underline and opt-in underline offset within one logical TEXT node. It rejects inline background, padding, dashed border, generated-content and list-marker run fields before dependency reads. The dedicated test verifies these rejections against the production helper. Whole-node underline or a background on an entire paragraph would not represent these inline contracts.

1. **Cite and italic quotation fonts.** Latin source uses the pinned Roboto Italic response. Arabic browser source requests italic from upright Noto Sans Arabic and permits style synthesis. Native family availability does not prove matching synthesized italic or support a made-up native face. Resolve native synthesis/face fidelity separately. Japanese glyph fallback also remains unresolved.
2. **Generated Q content.** The actual pseudo declarations are `open-quote` and `close-quote`, with `quotes:auto`. They are not literal authored quote strings. Actual 90-case accessibility evidence now records language-selected generated tokens separately from authored DOM copy: English “/”, Arabic ”/“, and Japanese 「/」. Actual 90-case geometry evidence records complete Q owner fragments and authored UTF-16 Range flow; all 30 Q cases expose exactly two extra owner fragments. These observed layout boxes and detached token capacity measurements are not directly measured pseudo glyph ink or proof of visual bidi ordering. A capability must distinguish generated ink from authored editable characters and preserve logical copy ownership. No quote glyph guess is emitted here.
3. **Outside list markers.** The actual OL/UL declarations are decimal/disc and outside. Each LI contains one Strong label followed by normal copy. Actual accessibility marker tokens are preserved verbatim, including spaces and Arabic AX decimal ordering; AX order is not visual placement. Outside marker ink still has no directly addressable DOM Element/Range rectangle in this capture path. Preserve each logical LI and source marker flow; do not reuse an unrelated TOC marker as accepted UA ink. A bounded native list profile needs source/native marker metrics and edit reflow evidence, or an explicitly gated source projection with measured marker ink.
4. **Inline boxes.** Code needs the actual system-monospace stack at requested weight 500, five-pixel left and right padding, source translucent background and full paragraph line flow. Abbr needs source inline border and title metadata. Proposed opt-in inline-box spans require validated UTF-16 boundaries, source box identity, zero-length source-box support where needed, measured line fragments and typed paint/size dependencies. Preflight must refuse stale ownership or copy that invalidates frozen line projection before permanent asset or scene writes. Keep ordinary rich text behavior unchanged when the feature is absent.

Exact DOM offsets, source inline-box rectangles, generated token characters and owner/authored line flow are now captured. The independently reviewed [generated source evidence](assets/semantic-generated-source/README.md) and its [pinned provenance](assets/semantic-generated-source/provenance.json) preserve 90 accessibility and 90 geometry diagnostics, all 290 original files and unchanged accepted source baseline. Replay reproduces source before/after fields, complete UTF-16 character slices and both frozen proofs exactly. The historical pre-close browser-log pin mismatch remains preserved. Detached measurement probes left all recorded source HTML, trees, styles, text rectangles, viewport and language unchanged.

Generated characters are known; Canvas/AX evidence does not establish source visual marker placement, actual fallback font bytes or native raster. Inline-box line flow and source edit/refusal semantics still need reviewed implementation. A finite source-line projection can then be reviewed against those records, retaining whole logical editable text and explicit refusal for unsupported reflow. It must not imply a general CSS inline formatting engine. API fields, native font/raster behavior and source edit contracts require independent review before shared runtime integration.

The dedicated source test confirms all 180 contexts, exact logical child ranges, the empty Arabic box, stable repeat output, wrong/missing mode refusal and source/font artifact refusal. It confirms unsupported native run fields refuse before dependency access. It creates no Figma nodes or assets. Native fonts, actual pseudo ink and outside-marker placement, inline layout, RTL/CJK fallback, arbitrary edit reflow, consumer publication and complete semantic coverage remain open. The generated-character source observation is passed; no source recipes or native list/italic implementation are inferred from it.

The current official [TextNode API](https://developers.figma.com/docs/plugins/api/TextNode/) documents native list options, hanging lists, spacing and indentation. This gives a concrete future list capability path, subject to source/native marker metrics and edit ownership checks. Its range API does not document inline padding. The official [TextDecorationStyle type](https://developers.figma.com/docs/plugins/api/TextDecorationStyle/) supports SOLID, WAVY and DOTTED; it does not provide DASHED. Therefore Abbr's source dashed border is not an accepted native underline mapping. [TextListOptions](https://developers.figma.com/docs/plugins/api/TextListOptions/) is a native type, not proof of browser UA marker equivalence.
