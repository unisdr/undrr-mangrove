# Semantic typography measured proposal

The audit captures 660 actual rendered source cases across five brands, English/Arabic/Japanese source locales, and viewport widths 390/1164. It uses 13 genuine BaseTypography stories. Paragraph default plus nine supported size utilities are selected through the actual Storybook Controls select; URL args demonstrably did not apply and that failed diagnostic is preserved. This is a source audit and proposed decomposition, with no recipes or native acceptance.

The proposed seven contract groups total 132 finite locale/viewport specimens across all brands. They are not 132 components, and each HTML tag is not counted as a separate component. The proposed groups are the whole six-level HeadingDemo (6), Paragraph default and nine actual size controls (60), Small/Cite/Hr callers (18), ordered/unordered/description lists (18), the genuine Figcaption caller (6), Quotation (6), and inline Mark/Code/Abbreviation callers (18). Full source case and geometry records are retained independently of this grouping.

Start with Heading and Paragraph, then Small/Hr/Figcaption and Descriptionlist. Heading really clamps levels 1 through 6, and its story has six actual logical heading nodes. Paragraph supports detail falling back to label and the exact allowed size values 150/200/250/300/400/500/600/800/900; the utility changes margins and line metrics as well as font size. Use actual captured all-mode values and genuine source role relationships, not a fixed 150% line-height assumption. Arabic h1 through h3 use Noto Kufi Arabic; lower headings retain Noto Sans Arabic. The RTL weight 700 override applies to all six headings.

Standalone Cite is inline browser italic with its actual line box, rather than the `.mg-content` block-citation treatment. Small retains its real paragraph wrapper. Hr retains both genuine paragraphs and both rules, including source margins and initial allocations. Figcaption is a separate real module that imports the existing 320 × 44 bundled `figcaption.jpg`, retains its source alt literal `icon`, applies 8.75px image padding, and places a genuine translated caption after the actual inline replaced-element baseline gap. It must not be substituted with the newer Images figure or forced to reuse a differently allocated caption master. Image licence acceptance is not established.

The ordered/unordered source List has three actual Strong label, colon and body entries. Descriptionlist has real dt/dd relationships, 137% line height, requested 600 term weight and responsive 20/30px indentation. Preserve whole logical rich list-item text and its source owning capacity. Outside UA list markers need a separate declared glyph/vector projection and source/native raster gate; the previously built page TOC does not establish standalone list equivalence.

Mark is a simple whole-span caller with a real padded background, responsive 12.5/16px font size, and actual UA black ink rather than nearby inherited body ink. This may be represented as one real owner FRAME and editable TEXT after its capacity/baseline contract is guarded. Code and Abbreviation are mixed logical paragraphs. Code has .875em requested 500 monospace, disabled ligatures, clone fragment backgrounds, padding and inset outlines. Abbreviation retains literal HTML/CSS labels, actual translated expansion-title metadata and a 2px dashed bottom border. Do not replace these paragraphs with independently editable sentence fragments or count styled rich ink alone as complete. They require measured finite decoration projection with explicit immutable/reflow fencing or a separately reviewed inline capability.

Quotation adds browser-generated opening and closing quote ink to an italic q element. This ink is absent from textContent; exact glyph identity and raster equivalence remain an implementation prerequisite. A copied pair of quote characters cannot silently become an exact authored source claim.

Fifteen actually observed remote font bodies are pinned by separate HTTP 200 body receipts and offline cmap probes. Roboto Regular/Bold/Italic bodies do not contain the Japanese probe glyphs, so browser/platform fallback is real and its selected face remains unresolved by the computed family string. Arabic italic relies on browser synthesis from upright declared Noto Sans Arabic, without established native italic equivalence. Native family inventory, font bytes, axes, synthesized styles, glyph fallback, CJK/bidi, baseline and raster acceptance remain distinct.

These source modules are exported from their own modules and absent from the package entry point. Foundational.jsx has no active visual export. Details, Accordion and the separately built Blockquote/QuoteHighlight contracts are not newly counted by this audit. Full arbitrary content flow, runtime semantics, native mode switching, library/consumer publication and human handoff remain separate gates.

`source-footprints.json.gz` is a lossless CSS-interned archive, not a lossy geometry summary. `measured-contexts.json` is a convenient projection; original full CSS, pseudo/marker styles, text-atom client rectangles, image bodies/dimensions and exact source copy remain in the raw/archive evidence. `source-input-hashes.json` guards the actual source inputs, while `frozen-audit-receipt.json` records unchanged inputs, exact archive restoration and the final source evidence hashes.
