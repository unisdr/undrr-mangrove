# AuthorImage source evidence

This directory is an external portable proposal for one finite source family with 216 presets, not a native acceptance packet. capture-archive-manifest.json pins all 300 complete raw captures and 960 unchanged PNG members. replay-source.py verifies their bytes and reconstructs profiles.json.gz byte-exact without writing archives or using network input.

recipes.cjs uses only repository-relative active evidence paths. Original /tmp paths in private source profiles, archive member provenance and historical receipts are historical identifiers; they are not active inputs. Source JPEG/SVG bodies are preserved unchanged. media-body-provenance.json records actual body metadata and historical HAR derivation pins. It does not attest licensing or native crop/raster parity.

The two node blend helpers contain the accepted R2 late INSTANCE membership fence. copied-builder-indexed-candidate.js is a pinned isolated artifact requiring separate shared builder/compiler adoption; it is not a default loader. Historical source/all-five receipts, independent base/R2 verdict and guard-only delta evidence retain their original scope. Eight failed candidate pixel predicates, missing native font/crop/gradient/effect/glyph/bidi/reflow and publication gates remain open.
