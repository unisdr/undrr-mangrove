# Generated quotation and list source diagnostics

This is source browser evidence, not a native component acceptance record.
Two sets of 90 actual cases cover five brands, English, Arabic and Japanese,
and 390px and 1164px viewports for quotation, ordered list and unordered list.
The deterministic compressed archives preserve all 290 original files exactly,
including actual capture drivers, raw DOM and accessibility snapshots,
geometry records, historical receipts and independent reviews.

The accessibility capture records generated quotation and marker characters
separately from authored DOM copy. Accessibility order is retained verbatim
and does not establish visual bidi placement. The geometry capture records
owner fragments, authored UTF16 Range flow and detached token capacity.
All 30 quotation cases have two owner fragments beyond authored Range boxes.
These are owner boxes, not directly measured pseudo glyph ink. Outside list
marker placement remains unmeasured. Native fonts, synthesis, fallback,
glyph raster, edited reflow and native integration remain open.

Run `python3 replay-archive.py` from this directory. It verifies archive and
baseline pins, rejects foreign or duplicate extraction entries, extracts to a
retained temporary directory, compares all recorded source fields with the
accepted baseline, verifies UTF16 character slices and reproduces both frozen
proofs byte for byte. It uses no browser or Figma calls and writes no archive
files. One historical absolute baseline path is explicitly relocated only in
the disposable comparator copy; original script bytes remain in the archive.

The first ink capture manifest was sealed before final browser-close logging.
Its original browser-log pin mismatch is preserved. Final provenance pins the
complete log and the actual driver used. The future driver merely seals after
close logging. There was no repeated capture or rewritten raw evidence.

The accepted baseline is copied unchanged from the held semantic-inline source
evidence. Including that baseline does not register its recipes or establish
native support for any of its six families.
