# Isolated SectionHeader cloud experiment

On 6 October 2026, the separate unpublished experiment
`GbVTvFbuWjoJr6Bf5t4fhg` received the two source SectionHeader variants in UNDRR.
The canonical kit, consumer and recovery files were untouched. Source preparation
used clean committed snapshots `cc4f2b03` and `0259573c`, shared identities and the
exact experiment target guard. Native source pixel parity across all five brands,
ordinary desktop rebuilding, library integration and publication remain open.

The initial scoped import created three variables and two text styles. Existing
collection/mode identity was reused, with pruning disabled. The build created
18 recorded scene IDs, including the variant set, masters, review scaffolding
and instance descendants. Its 63 prior recorded scene rows were retained;
only the operational MAIN and review root heights changed. Prior recorded
instance links/properties, text/font segments and explicit modes were preserved.

The first build exposed a review allocation issue: token-bound 600px FIXED
masters were preserved inside 344px review cells. The reviewed shared correction
uses the finite positive native FIXED master width plus existing padding as a
minimum. HUG variants keep their old allocation. The corrected SectionHeader
cells are 616px and wrap onto separate rows in the 720px browse grid. This fix
does not diagnose the tiny ordinary recovery-file drift.

The corrected native application created no nodes. Two new local consumers
were then created, linked to masters `26:18` and `26:22`; instances `33:17` and
`33:20` retain edited heading/description properties, including wrapping copy.
The corrected white review and consumer render were inspected independently.

Two further cloud rebuilds created zero nodes and reported no errors. Independent
review recomputed exact baseline/repeat equality for:

- 87 geometry records and 85 sizing records.
- Five explicit variable-mode records.
- Ten selected plain TEXT records, including fonts, styles, bindings, property
  references and hyperlinks.
- Fifteen instance/master/property records and the Header property definitions.

These are recorded projections, not every native property or a browser pixel
golden. Text comparison does not include every unrelated review caption. The
consumer content and component links survived both repeats.
