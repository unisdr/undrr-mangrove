## Core import choices on Starter

Use the existing single-mode UNDRR file. Import variables without pruning. For core foundation text styles, select `text/300`, `text/button`, `text/form-input` and the six existing `heading` sizes. Untick `display/900`, `display/1000` and `ui/tab`: their exact Roboto Condensed faces currently fail loading. Component builds import their own required source styles. No substitute fonts are approved.

Select all candidate families above and leave **Tab trigger**, **Tabs** and **Editorial CTA** unticked. Keep **Refresh bounded review geometry, keeping content** off for ordinary updates. Check the complete operation report before continuing. Missing fonts and partial errors are explicit failures for the affected scope.
