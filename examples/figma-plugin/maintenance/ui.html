2. Choose what to update

Brands
Load a token file to choose brands.

In a one-mode file, selecting one brand switches that mode. In the paid library, keep all five brands selected.

Text styles

Installed styles are selected after inspection. In a new file, only the nine core type roles start selected. Selecting additional roles creates local styles; publishing is a separate review.

Components and canvas boards are maintained separately. Token changes can change their appearance through existing bindings. This importer keeps omitted assets and does not publish.
