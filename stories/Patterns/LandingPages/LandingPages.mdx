# Landing page patterns

> **Note:** Tracked on [#1112](https://github.com/unisdr/undrr-mangrove/issues/1112). Review against the [component checklist](https://github.com/PreventionWeb/undrr-mangrove/blob/main/docs/REVIEW-CHECKLIST.md).

These examples compare three common UNDRR landing page structures side by side:
where the title sits, whether in-page navigation is needed, and how content is
grouped below the fold. Copy is illustrative; structure follows
[Building landing pages](?path=/docs/patterns-building-landing-pages--docs)
and current undrr.org patterns.

> **Integration note:** To build one of these pages on a UNDRR website, start
> with [Building landing pages](?path=/docs/patterns-building-landing-pages--docs)
> for the section structure, layout patterns and component choice, and
> [Drupal Gutenberg integration](?path=/docs/getting-started-integration-drupal-gutenberg--docs)
> for the blocks and their markup. AI tools can read both as one plain-text
> file at https://mangrove.undrr.org/llms-page-building.txt.

## Topic or initiative

A subject with several routes into it. Use a split hero for context, an icon row
for routes, and cards for recent material. If users start navigating repeatedly
between sections, graduate to a [Content hub](?path=/docs/patterns-content-hub--docs).

<Canvas of={Stories.TopicLanding} />

## Report or publication

One long document with stable sections. A coloured masthead carries title and
lede, and a contents sidebar helps readers jump to specific sections.

<Canvas of={Stories.ReportLanding} />

## Collection index

A directory to many items, not a subject page. Group covers into labelled rows
that link onward; skip the hero because the listings are the content.

## Choosing between them

| If the page…                                                      | Use                                                   | Because                                                            |
| ----------------------------------------------------------------- | ----------------------------------------------------- | ------------------------------------------------------------------ |
| Introduces a subject and points several ways into it              | Topic                                                 | The routes are the content; the hero sets the subject              |
| Is one long document people cite sections of                      | Report                                                | Contents links and a stable reading column matter more than routes |
| Exists to reach many items                                        | Collection index                                      | Grouped rows scan faster than prose, and no hero is needed         |
| Is returned to repeatedly, with lateral movement between sections | [Content hub](?path=/docs/patterns-content-hub--docs) | It needs persistent identity and section navigation                |

Use the locale toolbar for Arabic and the theme toolbar for other brands. Each
example sits under standard UNDRR header/global navigation so spacing is realistic.

## Building them in Drupal Gutenberg

Each example maps onto blocks an editor can place:

| Example          | Title and navigation                                                                                          | Body                                                                                                    |
| ---------------- | ------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------- |
| Topic            | Hero block with the split layout, then the on-this-page navigation block                                      | Icon cards for routes; vertical cards, or a search widget set up as a curated feed, for recent material |
| Report           | A full-width coloured columns block with the H1 and lede, and the table of contents block in its right column | Sections in a 20/60/20 reading column; stats cards at full width between them                           |
| Collection index | A level 1 heading and the table of contents block                                                             | An H3 per group, then five-column rows of book cards                                                    |

The guidance behind these choices, including section backgrounds, reading
column widths, spacing, the publication and data chart page shapes and the
editorial conventions for each section, is in
[Building landing pages](?path=/docs/patterns-building-landing-pages--docs).

## Composition

These pages compose shipped components (`Hero`, `IconCard`, `VerticalCard`,
`BookCard`, `TableOfContents`, `TextCta`, breadcrumb styles). `mg-landing-example`
styles and `UndrrChrome` are story-only scaffolding; no production exports or
hydration APIs are introduced here.

> **Implementation note (for contributors):** the tinted band and report masthead
> use `mg-container-full-width` to bleed inherited background to viewport edges
> from inside `mg-container`. This mirrors Gutenberg `wp:columns` wrappers and
> keeps examples aligned with real editor output.
