# Publication patterns

> See the [review checklist](https://mangrove.undrr.org/?path=/docs/contributing-build-a-component-review-checklist--docs) before modifying this archetype.

## Two full-page purposes

A **publication record** is a catalogue/detail entry for one work: description, optional complete cover, bibliographic identity, available documents and citation information. A **report landing page** is an editorially curated experience around a report, using selected findings, narrative sections and report actions. A long description alone does not turn a record into a landing page.

The [record specification](?path=/docs/patterns-content-publication-record-specification--docs) is provisional and **unimplemented**. The [existing full-page references](?path=/docs/patterns-content-publication-full-page--docs) show curated report landings only. Keep both within Publication; neither a CMS bundle nor a teaser/card projection establishes a canonical domain model or selects the full-page presentation automatically.
