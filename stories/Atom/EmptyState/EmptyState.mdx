# Empty state

What a list, table, chart or dashboard tile shows when it has nothing to show. A heading, an explanation, an optional glyph, and an optional action.

CSS only. There is no React component and no JavaScript, so Drupal, Twig, and plain HTML consumers can emit the markup directly.

## Usage

### HTML

```html
<div class="mg-empty-state">
  <div class="mg-empty-state__media">
    <svg
      viewBox="0 0 56 44"
      fill="none"
      stroke="currentColor"
      stroke-width="2"
      stroke-linejoin="round"
      aria-hidden="true"
      focusable="false"
    >
      <path d="M8 18 14 4h28l6 14" />
      <path d="M8 18h12l3 6h10l3-6h12v18a4 4 0 0 1-4 4H12a4 4 0 0 1-4-4z" />
    </svg>
  </div>
  <h2 class="mg-empty-state__title">No records yet</h2>
  <p class="mg-empty-state__description">
    Records you add or import will appear here.
  </p>
  <div class="mg-empty-state__actions">
    <a href="/records/add" class="mg-button mg-button-primary">Add a record</a>
  </div>
</div>
```

The glyph is a slot, not a fixed asset. Anything inside `__media` is sized to `--mg-empty-state-media-size`, and an SVG drawn with `currentColor` picks up `--mg-empty-state-media-color` so it re-themes with the rest of the component. The tray above is the one used in the stories; substitute anything that suits the content.

`__title` is a class, not a tag. Use the heading level the surrounding page calls for, or a `<p>` when the empty state sits inside a table cell where a heading would be out of place.

### Writing the message

Follow [docs/WRITING-SHORT.md](../../../docs/WRITING-SHORT.md). Say what is missing, then what to do about it. "No records match your filters. Clear the country filter to see all 1,204 records." beats "No data available."

## Accessibility

### What a screen reader should meet when a table has no rows

Keep the empty state **inside the table**, in a single `<td colspan>` that spans every column:

```html
<tbody>
  <tr>
    <td class="mg-empty-state-cell" colspan="3">
      <div class="mg-empty-state" role="status">…</div>
    </td>
  </tr>
</tbody>
```

Three things follow from that:

- The table keeps a valid row, so a screen reader in table navigation mode does not land in an empty grid or fall out of the table entirely.
- `colspan` covering every column means the message is read once, not once per column.
- `role="status"` makes it a polite live region, so when the rows disappear in response to a filter or a search the new message is announced without moving focus. **Only add `role="status"` when the emptiness is the result of something the user just did.** A page that renders empty on first load should omit it — a live region that fires on page load is noise.

The alternative, replacing the whole table with a `<div>`, also works and is simpler, but it loses the column headers, which are often the clearest signal about what the table would have contained.

### Other notes

- **SC 1.4.3 Contrast.** The title resolves to `--mg-color-text` (17.40:1 on white, 15.63:1 on the tinted panel). The description resolves to `--mg-color-neutral-500` (5.74:1 and 5.16:1).
- **SC 1.4.11 Non-text contrast.** The glyph is decorative and is always accompanied by text, so it is exempt — but `--mg-empty-state-media-color` is `--mg-color-neutral-400` (3.96:1 on white, 3.56:1 on the panel) so it clears the threshold anyway.
- **The glyph is decoration.** Give it `aria-hidden="true"` and `focusable="false"`. It must never be the only thing that says the list is empty.
- **Actions.** The action slot takes ordinary `.mg-button` markup, so focus rings, hit targets and hover states are inherited rather than reimplemented.
- **RTL.** Logical properties throughout. `--start` aligns to the inline start, so it is left-aligned in English and right-aligned in Arabic.

## Where these values come from

Layout and the compact variant come from the DELTA design system boards **"Empty State – Indicators and Charts"**, **"Empty State – Records List"** and **"Empty State – Analysis"** (Elements & Patterns → 03 Organisms and 04 Examples): a centred grey glyph above a short message, with a smaller form used inside indicator tiles and chart wells where the message is a bare "No data".

Two values were deliberately not reproduced:

- The boards set "No data" in **black at 25% opacity**, which composites to `#bfbfbf`, 1.84:1 against white, and fails SC 1.4.3 outright. `--mg-empty-state-text-color` is `--mg-color-neutral-500` (5.74:1), the nearest existing Mangrove token that clears 4.5:1.
- The boards draw the glyph at `#d9d9d9` (1.41:1). `--mg-empty-state-media-color` is `--mg-color-neutral-400` (3.96:1).

The action slot has no counterpart on the boards, which show message-only empty states. It is added here because an empty state a user cannot act on is a dead end; it is optional, and omitting it reproduces the Figma exactly.

Panel tints on the boards vary between mock instances (`#fafafa`, `#f3f2f8`, `#fbf2eb`) with no systematic value behind them, so `--panel` uses `--mg-color-neutral-25` rather than picking one.

## CSS class reference

| Class                          | Description                                     |
| ------------------------------ | ----------------------------------------------- |
| `.mg-empty-state`              | Base element                                    |
| `.mg-empty-state__media`       | Optional glyph slot (decorative)                |
| `.mg-empty-state__title`       | Heading text; use any heading level, or a `<p>` |
| `.mg-empty-state__description` | Supporting sentence                             |
| `.mg-empty-state__actions`     | Optional action slot                            |
| `.mg-empty-state--panel`       | Tinted well, for dashboard tiles and charts     |
| `.mg-empty-state--compact`     | Small form for indicator tiles                  |
| `.mg-empty-state--start`       | Inline-start alignment instead of centred       |
| `.mg-empty-state-cell`         | Resets padding on the `<td>` that holds it      |

### Theming

`--mg-empty-state-panel-radius` follows `--mg-card-border-radius`, so DELTA and MCR2030 inherit their own card rounding without a further override. No sub-brand overrides the remaining tokens.
