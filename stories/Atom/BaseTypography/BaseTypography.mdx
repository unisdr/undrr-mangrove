### Size prop

The optional `size` prop applies a responsive font-size utility class (`mg-u-font-size-{size}`). Use the controls below to preview each size.

| Size  | Mobile   | Desktop (>=48em) |
| ----- | -------- | ---------------- |
| `150` | 1.125rem | 1.125rem         |
| `200` | 1.25rem  | 1.25rem          |
| `250` | 1.4rem   | 1.4rem           |
| `300` | 1.6rem   | 1.6rem           |
| `400` | 1.6rem   | 1.8rem           |
| `500` | 1.8rem   | 2.3rem           |
| `600` | 2.3rem   | 3.2rem           |
| `800` | 3.2rem   | 3.6rem           |
| `900` | 3.6rem   | 4rem             |

When no `size` is set, the paragraph inherits its font size from the surrounding context.

## Changelog

- **2.3.1** — 2026-09-08 ([#1092](https://github.com/unisdr/undrr-mangrove/issues/1092)): Arabic typography now follows the computed language of each element rather than the page root, so a `lang="en"` island inside an Arabic page renders in the Latin families.
- **2.3** — 2026-09-01 ([#1086](https://github.com/unisdr/undrr-mangrove/pull/1086)): Aligned the enhanced `.mg-details` disclosure marker with stacked tabs by replacing directional triangles with tokenised circular plus/minus controls, logical RTL positioning, a 48px summary target, and tactile hover/press states. Bare `<details>` retains its native marker.
