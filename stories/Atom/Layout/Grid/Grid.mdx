# Grid system

This grid system is based on CSS Grid. The grid comes in two main layouts: auto layout and specified columns layout such as col-2.

<Canvas of={GridStories.DefaultGrid} meta={GridStories} />

### Usage

Use the grid to create a layout of your choice based on the design you want to achieve.

- copy the HTML of the variant you want and add the CSS file below to get started.

#### HTML for AUTO LAYOUT VARIANT:

```html
<div class="mg-grid"></div>
```

#### HTML for SPECIFIED COLUMN(S) LAYOUT VARIANT:

```html
<div class="mg-grid mg-grid__col-3"></div>
```

#### HTML for the asymmetric ARTICLE VARIANT:

Every variant above splits its space into equal fractions. `mg-grid--article`
is a different shape — a flexible column plus a fixed-width rail — for a page
layout like a reading column with a sidebar, not a card grid. It is what
powers `mg-reading--with-contents` (see the [Reading column](/docs/components-reading-column--docs)
doc); reach for it directly if you need the same shape outside that pattern.

```html
<div class="mg-grid mg-grid--article">
  <div><!-- flexible column --></div>
  <div><!-- 16rem fixed-width rail --></div>
</div>
```

#### CSS:

Add the base layout style from
