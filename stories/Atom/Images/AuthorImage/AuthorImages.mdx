# Author image

The Author image component now acts as a compact author block: portrait, name, job title, and organisation in one composable unit.

### Overview

Use it for author bylines, speaker cards, and profile callouts where the photo and the identity text need to stay together.
The Storybook examples use seeded Random User portraits so the images stay deterministic.
Pass `href` to make the whole block behave like a link.
Use `tone="inverse"` when the block sits on a dark background.
Leave `image` empty when you want a text-only author variant.
The default example grid also includes a text-only byline so the no-image state is visible without scrolling.

### Formatting

#### Default

The block supports horizontal and vertical stacked layouts. The portrait stays paired with a prominent name line and a secondary line for title/org. The accent can be primary, secondary, or tertiary.

### Behaviors

#### States

The component supports Small and Large sizes, horizontal and vertical layouts, plus three highlight colours:

- horizontal
- vertical
- linked
- inverse
- no image
- primary
- secondary
- tertiary
