# Author image

The Author image component now acts as a compact author card: portrait, name, job title, and organisation in one composable block.

### Overview

Use it for author bylines, speaker cards, and profile callouts where the photo and the identity text need to stay together.

### Formatting

#### Default

The card uses a portrait frame, a prominent name line, and a secondary line for title/org. The top accent can be primary, secondary, or tertiary.

### Behaviors

#### States

The component supports Small and Large sizes, plus three highlight colours:

- primary
- secondary
- tertiary
