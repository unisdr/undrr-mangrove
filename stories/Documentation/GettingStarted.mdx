## What is Mangrove?

Mangrove is the component library and design system of the United Nations Office
for Disaster Risk Reduction (UNDRR). It provides reusable UI for React and
server-rendered sites. Read <LinkTo kind="getting-started-about-mangrove" story="docs">About Mangrove</LinkTo>
for platform context and adoption limits. The code is Apache-2.0 licensed; the
UNDRR look and feel is proprietary.

This guide helps you use Mangrove in a site. To develop the library itself,
follow the [development guide](https://github.com/PreventionWeb/undrr-mangrove/blob/main/docs/DEVELOPMENT.md).

## Integration approaches

Choose the integration path that matches your stack.

### Vanilla HTML/CSS (simplest)

Load a theme stylesheet and copy the complete markup from the component docs. CSS-only components need no JavaScript; interactive components have their own module or hydration setup.

```html
<link
  rel="stylesheet"
  href="https://assets.undrr.org/mangrove/2.5.0/css/style.css"
/>
<span class="mg-tag">Organization</span>
```

For a complete page you can save and open, start with the
[vanilla guide's quick start](?path=/docs/getting-started-integration-vanilla-html-and-css--docs).

- [See on CodePen](https://codepen.io/khawkins98/pen/MYwbKwe): a working page with footer widget, analytics and messaging
- <LinkTo kind="getting-started-integration-vanilla-html-and-css" story="docs">
    Vanilla HTML/CSS guide
  </LinkTo>

### Sass integration

Import SCSS source files into your build process for custom themes and variable overrides.

- <LinkTo kind="getting-started-integration-sass-integration" story="docs">
    Sass integration guide
  </LinkTo>

### React components

Install via npm and import React components with props-based customization. The npm package ships pre-compiled components with React externalized.

```bash
yarn add @undrr/undrr-mangrove
```

Import components by their documented package subpaths; the published package
has no root entry point.

- <LinkTo kind="getting-started-integration-react-integration" story="docs">
    React integration guide
  </LinkTo>

### Hydration

For Drupal, Astro, or other server-rendered frameworks. The server renders HTML containers with `data-mg-*` attributes, then `createHydrator` mounts React behavior.

- <LinkTo kind="getting-started-integration-hydration-guide" story="docs">
    Hydration guide
  </LinkTo>

### CDN and versioning

All assets are served from versioned CDN endpoints. See the <LinkTo kind="getting-started-integration-cdn-reference" story="docs">CDN reference</LinkTo> for URLs and versioning details.

## Key principles

- When contributing visual or interaction changes, start with the <LinkTo kind="design-decisions-experience-principles" story="docs">experience principles</LinkTo>
- All CSS classes use the `mg-` prefix (e.g., `mg-card`, `mg-form__input`) to avoid conflicts with your styles
- Components use semantic HTML with ARIA attributes for accessibility
- Use the JavaScript setup documented for each interactive component
- Supports modern evergreen browsers: see <LinkTo kind="getting-started-browser-support" story="docs">browser support</LinkTo>
- Supports right-to-left (RTL) layouts: components adapt automatically when `dir="rtl"` is set on the document

For deeper context, see the <LinkTo kind="contributing-architecture" story="docs">architecture guide</LinkTo>.
