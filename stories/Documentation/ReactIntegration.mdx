Use Mangrove React components for props-driven UI with built-in accessibility
and UNDRR branding. For broader context, review
**<LinkTo kind="getting-started-about-mangrove" story="docs">About Mangrove</LinkTo>**.

## Installation

```bash
yarn add @undrr/undrr-mangrove
```

Mangrove requires React 18 or later as a peer dependency. If you do not already have React installed:

```bash
yarn add react react-dom
```

## Importing components

**Import one component per subpath. There is no package root.**

```jsx
import { StatsCard } from '@undrr/undrr-mangrove/components/StatsCard.js';
import { Pager } from '@undrr/undrr-mangrove/components/Pager.js';
import ShareButtons from '@undrr/undrr-mangrove/components/ShareButtons.js';
```

`import { StatsCard } from '@undrr/undrr-mangrove'` does not work, and never
has on any published version. The tarball ships no bundled entry point — only
the `components/`, `css/`, `scss/`, `js/`, `fonts/` and `error-pages/`
directories — so a bare root import fails to resolve. From 2.0.0 the package
stops advertising one at all
([#1252](https://github.com/unisdr/undrr-mangrove/issues/1252)). Each component
is its own bundle, which is also what keeps a page from downloading the whole
library to use one card.

**Check whether the binding is named or default.** It is not uniform. Most
bundles export the component under its own name, a few export it only as a
default, and getting it wrong gives you `undefined` rather than an error at the
import. The table below lists the working import line for every published
component; the [machine-readable manifest](https://mangrove.undrr.org/llms.txt)
carries the same lines, generated from the built bundles.

To mount components into server-rendered HTML containers, the hydration runtime
is a subpath too, with a default export:

```jsx
import createHydrator from '@undrr/undrr-mangrove/components/hydrate.js';
```

## Including styles

Mangrove does not expose CSS at a conventional npm `dist/css/` path. Use one of
these:

**Option A: CDN (recommended for most consumers)**

Load the compiled CSS from UNDRR's CDN. Pick the theme that matches your site:

```html
<!-- UNDRR default theme -->
<link
  rel="stylesheet"
  href="https://assets.undrr.org/mangrove/2.0.0/css/style.css"
/>

<!-- Or a site-specific theme -->
<link
  rel="stylesheet"
  href="https://assets.undrr.org/mangrove/2.0.0/css/style-preventionweb.css"
/>
```

Available theme files: `style.css`, `style-preventionweb.css`, `style-mcr.css`,
`style-irp.css`, `style-delta.css`, and combined `style-all.css`. Legacy 10px-root
variants were removed in 2.0; Mangrove now assumes a 16px root. See
[v2.0 release notes](?path=/docs/getting-started-release-notes-v2-0--docs) for migration.

See the <LinkTo kind="getting-started-integration-cdn-reference" story="docs">CDN reference</LinkTo> for the full list of available assets and versioned URLs.

**Option B: Sass integration**

If your build pipeline supports Sass, you can import the source SCSS files directly and customize variables. See the <LinkTo kind="getting-started-integration-sass-integration" story="docs">Sass integration guide</LinkTo> for setup instructions.

`ShowMore` and `Tab` are flagged `importRequiresDom: true` in the AI manifest.
Those bundles read `document` while they load, so the import above throws
`document is not defined` in Node and during server-side rendering. It is
correct in a browser and through a bundler. On a server-rendered page, load it
from a dynamic import after mount, or use the vanilla module and hydration
contract instead. Every other bundle imports anywhere.

## Usage examples

### StatsCard

```jsx
import { StatsCard } from '@undrr/undrr-mangrove/components/StatsCard.js';

function DashboardStats() {
  return (
    <StatsCard
      title="Global impact"
      variant="default"
      stats={[
        {
          icon: 'mg-icon mg-icon-globe',
          label: 'Target A',
          value: '195',
          bottomLabel: 'UN member states',
          summaryText: 'Working together on disaster risk reduction',
        },
        {
          value: '45%',
          label: 'Target B',
          bottomLabel: 'Reduction in mortality',
        },
      ]}
    />
  );
}
```

Props: `title` (string), `stats` (array of objects with `icon`, `label`, `value`, `bottomLabel`, `summaryText`, `link`), `variant` (`"default"` | `"compact"` | `"highlighted"` | `"negative"`), `className`.

### Pager

```jsx
import { useState } from 'react';
import { Pager } from '@undrr/undrr-mangrove/components/Pager.js';

function PaginatedList() {
  const [page, setPage] = useState(1);

  return (
    <div>
      {/* Your list content here */}
      <Pager page={page} totalPages={10} onPageChange={setPage} />
    </div>
  );
}
```

Props: `page` (number, required), `totalPages` (number), `onPageChange` (function, required), `isLoading` (boolean), `layout` (`"centered"` | `"bar"`), `range` (object with `start` and `end`), `showJumpTo` (boolean), `emptyState` (string).

### ShareButtons

```jsx
import ShareButtons from '@undrr/undrr-mangrove/components/ShareButtons.js';

function ArticlePage() {
  return (
    <ShareButtons
      labels={{
        mainLabel: 'Share this page',
        onCopy: 'Copied',
      }}
      SharingSubject="Disaster risk reduction report"
      SharingTextBody="Check out this report: "
    />
  );
}
```

Props: `labels` (object with `mainLabel` and `onCopy` strings), `SharingSubject` (string), `SharingTextBody` (string).

### QuoteHighlight

```jsx
import QuoteHighlight from '@undrr/undrr-mangrove/components/QuoteHighlight.js';

function QuoteSection() {
  return (
    <QuoteHighlight
      quote="Disaster risk reduction is everyone's business."
      attribution="Mami Mizutori"
      attributionTitle="Special Representative of the Secretary-General"
      variant="line"
      backgroundColor="light"
    />
  );
}
```

Props: `quote` (string, required), `attribution` (string), `attributionTitle` (string), `imageSrc` (string), `imageAlt` (string), `variant` (`"line"` | `"image"`), `backgroundColor` (`"light"` | `"dark"` | `"bright"`), `alignment` (`"full"` | `"left"` | `"right"`).

### Notice

```jsx
import { Notice } from '@undrr/undrr-mangrove/components/Notice.js';

function DraftPage() {
  return (
    <Notice
      variant="warning"
      title="Unsaved changes"
      description="You have modified draft indicators that have not yet been published."
      headingLevel="h2"
      isDismissible
      onDismiss={() => trackDismiss()}
    />
  );
}
```

Props: `variant` (`"info"` | `"warning"` | `"negative"` | `"positive"`), `title` (string), `description` (string), `headingLevel` (string), `isDismissible` (boolean), `onDismiss` (function), `actions` (node).

`Snackbar`, the auto-dismissing toast built on `Notice`, has no webpack entry
and so ships in no bundle. It is usable from this repository and visible in
Storybook, but there is nothing to import from npm.

## Server-rendered hydration

For server-rendered HTML (Drupal, Astro, etc.), use `createHydrator` to scan
matching containers, extract props from `data-` attributes, and mount
components.

Example below shows the **Drupal wrapper pattern** with `@mangrove/*` import-map
aliases (injected by `mangrove-components.js` in `undrr_common`). In standard
React apps, import the `@undrr/undrr-mangrove/components/…` subpaths shown
above and pass props.

```jsx
// Drupal wrapper script — uses @mangrove/* import map aliases (resolved by mangrove-components.js)
import createHydrator from '@mangrove/hydrate';
import ShareButtons, { fromElement } from '@mangrove/ShareButtons';

const hydrator = createHydrator({
  selector: '[data-mg-share-buttons]',
  component: ShareButtons,
  fromElement,
});

// Re-scan when Drupal adds new DOM (AJAX, BigPipe, modals, Views infinite scroll)
Drupal.behaviors.mangroveShareButtons = {
  attach(context) {
    hydrator.update(context);
  },
};
```

`fromElement` maps container data attributes to props. Components with hydration
support already ship their own `fromElement`.

See the [hydration guide](https://github.com/unisdr/undrr-mangrove/blob/main/docs/HYDRATION.md) for the full API, including `update()`, `unmountAll()`, and error handling options.

## TypeScript

TypeScript works in development, but the published package does not yet include
`.d.ts` files. In consuming projects, declare the modules locally — one per
subpath, matching the specifier you import and the binding that subpath
exports, because there is no root module to declare:

```ts
// mangrove.d.ts
declare module '@undrr/undrr-mangrove/components/StatsCard.js' {
  import { ComponentType } from 'react';

  export const StatsCard: ComponentType<{
    title?: string;
    stats?: Array<{
      icon?: string;
      label?: string;
      value: string | number;
      bottomLabel?: string;
      summaryText?: string;
      link?: string;
    }>;
    variant?: 'default' | 'compact' | 'highlighted' | 'negative';
    className?: string;
  }>;
}

declare module '@undrr/undrr-mangrove/components/Pager.js' {
  import { ComponentType } from 'react';

  export const Pager: ComponentType<{
    page: number;
    totalPages?: number;
    onPageChange: (page: number) => void;
    isLoading?: boolean;
    layout?: 'centered' | 'bar';
    ariaLabel?: string;
    range?: { start: number; end: number };
    rangeLabel?: string;
    showJumpTo?: boolean;
    jumpToLabel?: string;
    jumpToAction?: string;
    emptyState?: string;
    emptyAction?: { label: string; onClick: () => void };
  }>;
}

// A default-export bundle is declared with `export default` instead:
declare module '@undrr/undrr-mangrove/components/ShareButtons.js' {
  import { ComponentType } from 'react';

  const ShareButtons: ComponentType<{
    labels?: { mainLabel?: string; onCopy?: string };
    SharingSubject?: string;
    SharingTextBody?: string;
  }>;
  export default ShareButtons;
}

// Add declarations for other components as needed
```

Use component PropTypes (Storybook controls) as the source of accepted props.

## Testing

Components from Mangrove can be tested with React Testing Library like any other React component:

```jsx
import { render, screen } from '@testing-library/react';
import { Pager } from '@undrr/undrr-mangrove/components/Pager.js';

test('renders pagination with correct page', () => {
  const handlePageChange = jest.fn();

  render(<Pager page={3} totalPages={10} onPageChange={handlePageChange} />);

  expect(
    screen.getByRole('navigation', { name: /pagination/i })
  ).toBeInTheDocument();
});
```
