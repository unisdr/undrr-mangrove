## Use Mangrove

For most UNDRR sites, start with the versioned stylesheet hosted on `assets.undrr.org`. It requires no package manager or build step and gives teams a stable, centrally hosted release.

<Source
  language="html"
  code={
    '<link rel="stylesheet" href="https://assets.undrr.org/static/mangrove/2.0.0-alpha.4/css/style.css" />'
  }
/>

Use npm when a project needs Sass customization, React components, local bundling, or a package-managed dependency workflow:

<Source language="bash" code="npm install @undrr/undrr-mangrove" />

Each UNDRR property themes components independently. The shared layer is the semantic content structure—the parts that let syndicated content render correctly and accessibility fixes propagate to every site at once. Mangrove is used on [undrr.org](https://www.undrr.org), [PreventionWeb](https://www.preventionweb.net), [MCR2030](https://mcr2030.undrr.org), and partner sites.
