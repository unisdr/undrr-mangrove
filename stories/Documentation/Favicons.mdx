## Recommended markup

Replace `{brand}` with the directory name from the Brands table above:

```html
<link
  rel="icon"
  href="https://assets.undrr.org/favicons/{brand}/v1/favicon.ico"
  sizes="32x32"
/>
<link
  rel="icon"
  href="https://assets.undrr.org/favicons/{brand}/v1/favicon-192.png"
  sizes="192x192"
  type="image/png"
/>
<link
  rel="apple-touch-icon"
  href="https://assets.undrr.org/favicons/{brand}/v1/apple-touch-icon.png"
/>
```

For example, PreventionWeb:

```html
<link
  rel="icon"
  href="https://assets.undrr.org/favicons/pw/v1/favicon.ico"
  sizes="32x32"
/>
<link
  rel="icon"
  href="https://assets.undrr.org/favicons/pw/v1/favicon-192.png"
  sizes="192x192"
  type="image/png"
/>
<link
  rel="apple-touch-icon"
  href="https://assets.undrr.org/favicons/pw/v1/apple-touch-icon.png"
/>
```

For PWA `manifest.json`:

```json
{
  "icons": [
    {
      "src": "https://assets.undrr.org/favicons/{brand}/v1/favicon-192.png",
      "sizes": "192x192",
      "type": "image/png"
    },
    {
      "src": "https://assets.undrr.org/favicons/{brand}/v1/favicon-512.png",
      "sizes": "512x512",
      "type": "image/png"
    }
  ]
}
```

## Integration

### Drupal themes

CDN favicons are injected automatically by `undrr_common_page_attachments_alter()` for all child themes. The `mangrove_cdn_environment` setting controls whether favicons load from production or testing CDN.

### Astro microsites

Use `BaseLayout.astro` with the `theme` prop. Optional `favicon` prop overrides the default:

```astro
<!-- Favicon matches theme -->
<BaseLayout theme="preventionweb" />

<!-- Override favicon -->
<BaseLayout theme="irp" favicon="undrr" />
```

### Other consumers

Any site can reference the CDN paths directly. Use the recommended markup above with the appropriate brand directory.

## Adding a new brand

1. Add a `favicons/{brand}/v1/` directory in [shared-web-assets](https://gitlab.com/undrr/common/shared-web-assets)
2. Place a square `source-icon.png` (512px minimum, transparent background)
3. Run `npm run generate-favicons -- {brand}` (requires ImageMagick 7+)
4. Commit and push — CI deploys to CDN
5. Update the Drupal theme mapping and/or the microsites mapping

## Versioning

Never modify files in an existing version directory. Create a `v2/` directory to update a brand's favicons.
