# CTA

A call-to-action block brings a heading, supporting copy and a next step together.
Use it for an invitation, a resource, a campaign or a short signup form. TextCta
provides the layout and visual treatment; its contents determine the purpose.

Use `buttons` for action links, or compose a form or other content through
`children`. The block does not submit forms, manage subscriptions or connect to a
service. For an individual action without a promotional block, use

<LinkTo kind="Components/Buttons/Buttons" story="Editorial CTA">
  a CTA button
</LinkTo>
.

## Choose the emphasis

Colour and emphasis are separate decisions. `variant` chooses the theme accent;
`tone` chooses how strongly it appears. Existing CTAs keep the strong default.

| Treatment                 | Useful for                                                             | Text and actions                                                                |
| ------------------------- | ---------------------------------------------------------------------- | ------------------------------------------------------------------------------- |
| `tone="soft"`             | Newsletter promotion, supporting invitations, blocks within an article | Pale accent surface, dark text and ordinary button styling                      |
| `tone="strong"` (default) | Campaigns, prominent invitations, major next steps                     | Solid accent surface, light text and buttons styled for the coloured background |

### Soft

A quieter block can invite action without dominating the surrounding content.
Change `variant` to compare accent colours, or `tone` to compare emphasis.

## Compose a form

A newsletter signup is one use of the block. The example below supplies an
independent FormAction as `children`, using the soft tone and start-aligned copy.
Its submission is a local demonstration only: it sends no data and creates no
subscription.

<Canvas of={TextCtaStories.Newsletter} />

```jsx
<TextCta
  headline="Stay informed"
  text="Choose the updates that matter to you."
  tone="soft"
  centered={false}
>
  <YourSignupForm />
</TextCta>
```

For several fields, supply a regular form layout with its action after the fields.
The site owns its choices, validation, privacy information and submission service;
none of those require newsletter-specific CTA props.

## Arrange the content

### With an image

An optional image sits at the inline end of the copy and stacks on narrow screens.
Its placement follows text direction. Supply meaningful `imageAlt` text, or an
empty string for a decorative image.

<Canvas of={TextCtaStories.WithImage} />

### Inline actions

Use `layout="inline"` for a wide banner with copy and action links side by side.
It stacks on narrow screens. Supplying composed `children` selects a stacked layout so the copy, content and
buttons each retain the full available width.

<Canvas of={TextCtaStories.Inline} />

### Alignment and size

Text-only CTAs are centred by default. Set `centered={false}` to align content to
the start edge; this is generally easier to scan for forms and longer copy. An
image or inline layout disables centring automatically.

`headlineLevel` chooses the semantic heading level independently of
`headlineSize`. `padding` can override the theme spacing when a placement needs
more or less room. Body copy and images are optional.

## Accent colours

All four accents support both tones and follow the selected site theme. Secondary
is a colour choice, not a synonym for the soft tone.

| `variant`           | Accent source           |
| ------------------- | ----------------------- |
| `primary` (default) | Main theme accent       |
| `secondary`         | Secondary theme accent  |
| `tertiary`          | Tertiary theme accent   |
| `quaternary`        | Quaternary theme accent |

Use the controls above to compare them. Prefer theme accents over custom colours
so text and action treatments stay coordinated across sites.

## Props

| Prop              | Type       | Default     | Description                                                                                                                        |
| ----------------- | ---------- | ----------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| `eyebrow`         | String     | -           | Optional short label above the headline                                                                                            |
| `headline`        | String     | -           | Banner heading text                                                                                                                |
| `headlineSize`    | String     | `'600'`     | Font size token applied as `mg-u-font-size-{value}` (e.g. `'400'`, `'600'`, `'800'`)                                               |
| `headlineLevel`   | Number     | `2`         | Semantic heading level (2–6). Controls the HTML element independently of visual size                                               |
| `text`            | String     | -           | Body text (HTML supported via `dangerouslySetInnerHTML`)                                                                           |
| `children`        | React node | —           | Composed content below the copy, before any buttons. Supply a native form or other content; the CTA does not manage its behaviour. |
| `buttons`         | Array      | `[]`        | Array of button objects: `{ label, url, type }`                                                                                    |
| `tone`            | String     | `'strong'`  | Surface emphasis: `'strong'` or `'soft'`. Soft uses a pale accent wash with dark text and normal button styling.                   |
| `variant`         | String     | `'primary'` | Color variant: `'primary'`, `'secondary'`, `'tertiary'`, `'quaternary'`                                                            |
| `backgroundColor` | String     | -           | Custom CSS background color (overrides variant)                                                                                    |
| `padding`         | String     | -           | Custom CSS padding (e.g. `'8rem 0'`), overrides theme token                                                                        |
| `image`           | String     | -           | Image URL displayed alongside text (triggers side-by-side layout)                                                                  |
| `imageAlt`        | String     | `''`        | Alt text for the image                                                                                                             |
| `centered`        | Boolean    | `true`      | Center-align content (auto-disabled when `image` is set)                                                                           |
| `layout`          | String     | `'stacked'` | Content/action arrangement: `'stacked'` or `'inline'`                                                                              |
| `className`       | String     | -           | Additional CSS classes                                                                                                             |

### Button object

| Property  | Type    | Default     | Description                                        |
| --------- | ------- | ----------- | -------------------------------------------------- |
| `label`   | String  | Required    | Button text                                        |
| `url`     | String  | `'#'`       | Button link URL                                    |
| `type`    | String  | `'Primary'` | Button style: `'Primary'` or `'Secondary'`         |
| `variant` | String  | `'Default'` | Button treatment: `'Default'` or editorial `'CTA'` |
| `outline` | Boolean | `false`     | Use the transparent outline treatment              |
| `target`  | String  | -           | Link browsing context, such as `'_blank'`          |
| `rel`     | String  | -           | Link relationship tokens                           |

## Integration guidance

Pass a form or other React content as `children` to reuse the CTA shell. Its
heading, copy, optional image and existing button API stay independent of the
content. Use `centered={false}` for form compositions and give the form an
appropriate contrasting surface. Supplying content selects a stacked layout even when `layout="inline"`. Form behaviour, validation and service integration belong to the
caller.

For Drupal-owned forms, render the CTA classes directly around the native form.
Do not apply `data-mg-text-cta` hydration to custom form content: the current
hydrator supports the existing text/button data model, not arbitrary children.

## Server-rendered / CDN usage

The new `tone` and `children` options are shown from the local build and are not
available in the published alpha.4 bundle. Use a release containing these changes
when integrating them. The CDN example below demonstrates the existing button API.

TextCta supports [layered hydration](https://github.com/unisdr/undrr-mangrove/blob/main/docs/HYDRATION.md). Use data attributes on a container element:

```html
<div
  data-mg-text-cta
  data-eyebrow="Registration open"
  data-headline="Join the global platform"
  data-text="<p>Register now for the Global Platform.</p>"
  data-buttons='[{"label":"Register","url":"/register"},{"label":"Learn more","url":"/about","type":"Secondary"}]'
  data-variant="primary"
  data-layout="inline"
></div>
```

| Attribute               | Default     | Description                                              |
| ----------------------- | ----------- | -------------------------------------------------------- |
| `data-eyebrow`          | `''`        | Optional short label above the headline                  |
| `data-headline`         | `''`        | Banner heading text                                      |
| `data-headline-size`    | `'600'`     | Font size token (e.g. `'400'`, `'600'`, `'800'`)         |
| `data-headline-level`   | `2`         | Semantic heading level (2–6)                             |
| `data-text`             | `''`        | Body HTML (sanitized via DOMPurify)                      |
| `data-buttons`          | `[]`        | JSON array of button objects: `{ label, url, type }`     |
| `data-tone`             | `'strong'`  | `'strong'` or `'soft'`; available from the next release  |
| `data-variant`          | `'primary'` | `'primary'`, `'secondary'`, `'tertiary'`, `'quaternary'` |
| `data-background-color` | -           | Custom CSS background color                              |
| `data-padding`          | -           | Custom CSS padding                                       |
| `data-image`            | -           | Image URL (triggers side-by-side layout)                 |
| `data-image-alt`        | `''`        | Alt text for the image                                   |
| `data-centered`         | `'true'`    | `'true'` or `'false'`                                    |
| `data-layout`           | `'stacked'` | `'stacked'` or `'inline'`                                |

```js
import createHydrator from 'https://assets.undrr.org/mangrove/2.0.0-beta.1/components/hydrate.js';
import TextCta, {
  fromElement,
} from 'https://assets.undrr.org/mangrove/2.0.0-beta.1/components/TextCta.js';
createHydrator({
  selector: '[data-mg-text-cta]',
  component: TextCta,
  fromElement,
});
```

See the [hydration guide](https://github.com/unisdr/undrr-mangrove/blob/main/docs/HYDRATION.md) for the full API and integration details.

## Accessibility

- Uses semantic `<section>` element with `aria-labelledby` pointing to the headline (falls back to `aria-label="Call to action"` when no headline is provided)
- Headline renders as a proper heading element (`<h2>` by default). Use `headlineLevel` to match the document outline
- Button text provides clear action labels
- Soft tone uses dark text; strong tone uses light text. Check contrast for the chosen theme and any custom backgrounds or child content.
- Soft-tone actions inherit normal button focus styles; strong-tone action links use the inverse focus treatment.
- Composed forms need visible labels, correctly grouped choices and accessible error/confirmation feedback supplied by their owner.
