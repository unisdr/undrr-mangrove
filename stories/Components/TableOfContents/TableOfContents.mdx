# Table of contents (on this page navigation)

The TableOfContents component provides a quick, inline index of page sections.

### Overview

Use TableOfContents on long-form pages with multiple sections where readers may jump between headings.

### Formatting

#### Default

It renders an optional title ("On this page") plus a numbered or unnumbered list of section links.

### Props

| Prop        | Type    | Default | Description                                                                      |
| ----------- | ------- | ------- | -------------------------------------------------------------------------------- |
| tocData     | Array   | []      | An array of objects, each representing a section with `id` and `text` properties |
| showNumbers | Boolean | false   | If true, renders the list as an ordered list (numbered)                          |

### Content

The TableOfContents component accepts an array of objects, each representing a section of the page. Each object should have an `id` (corresponding to the section's HTML id) and a `text` (the display text for the link).

### Behaviors

#### States

There are two states: Default and Hover.

1. Default: The normal display of the table of contents.
2. Hover: The appearance changes when the mouse hovers over a link.

### Usage:

#### React applications

To use the TableOfContents component in your React application:

1. Import the component:

   ```jsx
   import TableOfContents from './path/to/TableOfContents';
   ```

2. Prepare your table of contents data:

   ```jsx
   const tocData = [
     { id: 'section-1', text: 'Section 1 Title' },
     { id: 'section-2', text: 'Section 2 Title' },
   ];
   ```

3. Use the component in your JSX:
   ```jsx
   <TableOfContents tocData={tocData} showNumbers={false} />
   ```

#### DOM Scraping (auto-init)

The TOC can auto-initialize from a `data-mg-table-of-contents` element. Load the
standalone script from the UNDRR CDN (or npm as
`@undrr/undrr-mangrove/js/table-of-contents.js`):

```html
<script
  type="module"
  src="https://assets.undrr.org/mangrove/2.0.0-beta.1/js/table-of-contents.js"
></script>
```

Add your HTML. Use `data-mg-table-of-contents-content` to specify which element
contains the headings to scan:

```html
<article class="mg-content">
  <h1 id="section-1">Welcome to the example</h1>
  <p>The above header is excluded as it is the H1</p>
  <section
    data-mg-table-of-contents
    data-mg-table-of-contents-content=".mg-content"
    data-mg-table-of-contents-title="Title name can be optionally passed"
    class="mg-table-of-contents"
  ></section>
  <h2 id="section-2">Section 2</h2>
  <p>Content for section 2...</p>
  <h2 id="section-3">Section 3</h2>
  <p>Content for section 3...</p>
  <h2 id="section-4" class="mg-table-of-contents--exclude">Section 4</h2>
  <p>excluded with .mg-table-of-contents--exclude</p>
  <h3 id="section-5">Sub-section 5</h3>
  <p>Skipped as it is a h3</p>
  <h2 id="section-6">Section 6</h2>
  <p>Content for section 6...</p>
</article>
```

The script auto-initializes on `DOMContentLoaded`. For manual control, import the
function directly:

```js
import { mgTableOfContents } from 'https://assets.undrr.org/mangrove/2.0.0-beta.1/js/table-of-contents.js';

const contentElement = document.querySelector('.mg-content');
const tocElement = document.querySelector('[data-mg-table-of-contents]');
if (contentElement && tocElement) {
  mgTableOfContents(contentElement, tocElement);
}
```

**Data attributes:**

| Attribute                                  | Default          | Description                                                    |
| ------------------------------------------ | ---------------- | -------------------------------------------------------------- |
| `data-mg-table-of-contents`                | —                | Required. Activates the component.                             |
| `data-mg-table-of-contents-content`        | `document.body`  | CSS selector for the content area to scan for headings.        |
| `data-mg-table-of-contents-title`          | `"On this page"` | Title text. Set to `"hidden"` for screen-reader-only.          |
| `data-mg-table-of-contents-show-title`     | `"true"`         | Set to `"false"` to hide the title entirely.                   |
| `data-mg-table-of-contents-skip-auto-init` | —                | Opt out of auto-init; call `mgTableOfContentsInit()` manually. |

Notes:

- See the Scraped Content story for an example.
- Only `h2` headings are included.
- Exclude headings with `.mg-table-of-contents--exclude`.
- Ensure the component CSS is loaded.

### Interactions

- Hover state appears when the mouse is over a link.
- Clicking a link scrolls the page to the corresponding section.

### Accessibility

Ensure that the sections referenced in the TableOfContents have proper heading tags (h1, h2, etc.) and unique id attributes for keyboard navigation and screen reader compatibility.
