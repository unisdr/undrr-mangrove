# Scroll container

The Scroll Container component provides a responsive horizontal scrolling container for content that exceeds the available width.

## With navigation arrows

A scroll container with navigation arrows for easier scrolling. The arrows appear at the top of the container when content overflows horizontally and the `showArrows` prop is set to `true`. The arrows will only be visible when there is content to scroll to in that direction.

<div style={{ maxWidth: '800px', margin: '0 auto', position: 'relative' }}>
  <ScrollContainer showArrows={true} itemWidth="350px">
    {scrollCardExamples.map((card, i) => (
      <ScrollExampleCard card={card} index={i} key={card.title} />
    ))}
  </ScrollContainer>
</div>

> **Note:** Arrows only appear when content overflows horizontally and will be hidden on mobile devices.

## With custom step size

A scroll container with custom step size for navigation arrows. By default, clicking an arrow scrolls by half the container width, but you can customize this with the `stepSize` prop (in pixels).

<div style={{ maxWidth: '800px', margin: '0 auto', position: 'relative' }}>
  <ScrollContainer showArrows={true} stepSize={200}>
    {scrollCardExamples.map((card, i) => (
      <ScrollExampleCard card={card} index={i} key={card.title} />
    ))}
  </ScrollContainer>
</div>

> **Note:** In this example, clicking an arrow will scroll by 200 pixels instead of the default container width.

## With single child

This demonstrates a use case of where a single div may wrap all the child content, providing its own grid functionality.

<div style={{ maxWidth: '800px', margin: '0 auto', position: 'relative' }}>
  <ScrollContainer showArrows={true}>

## Usage

```jsx
import { ScrollContainer } from '@components';

const MyComponent = () => (
  <ScrollContainer height="500px" showArrows={true}>
    {/* Your scrollable content here */}
    <div>Item 1</div>
    <div>Item 2</div>
    <div>Item 3</div>
  </ScrollContainer>
);
```

## Props

| Prop         | Type    | Default  | Description                                         |
| ------------ | ------- | -------- | --------------------------------------------------- |
| children     | node    | Required | Content to be displayed inside the scroll container |
| height       | string  | 'auto'   | Custom height for the container                     |
| minWidth     | string  | 'auto'   | Minimum width for the container                     |
| itemWidth    | string  | 'auto'   | Width for individual items within the container     |
| padding      | string  | '0'      | Padding inside the container                        |
| className    | string  | ''       | Additional CSS class names                          |
| showArrows   | boolean | false    | Whether to show navigation arrows                   |
| stretchItems | boolean | false    | Stretch mixed-length items to a shared row height   |
| stepSize     | number  | null     | Custom step size for arrow navigation (in pixels)   |

## Behaviors

1. **Desktop**:

   - Click and drag to scroll horizontally
   - Optional navigation arrows for controlled scrolling
   - Mouse wheel scrolling works as expected

2. **Mobile**:
   - Native touch scrolling behavior
   - Navigation arrows are hidden on mobile devices
   - Optimized for touch interactions

## Accessibility

### Arrow button labels

When `showArrows` is enabled, the left and right navigation buttons have `aria-label="Scroll left"` and `aria-label="Scroll right"` respectively. Buttons are automatically `disabled` when there is no content to scroll in that direction, which prevents activation and communicates state to assistive technologies.

### Container semantics

- The component wraps content in a `<section>` element, providing a sectioning landmark
- The arrow buttons are grouped inside a `<nav>` element with class `mg-scroll__nav`

### Keyboard support

The scroll container itself does not implement custom keyboard event handlers. Users can scroll horizontally using native browser mechanisms (e.g., Shift+scroll wheel on desktop). The arrow buttons are standard `<button>` elements and are reachable via Tab and activatable with Enter or Space.

### Known limitations

These are gaps that affect users or accessibility auditors:

- Screen readers may announce the scroll container as an unlabelled section (the `<section>` has no `aria-label`)
- The arrow button group has no accessible label describing its purpose
- There are no live announcements when the scroll position changes
- No keyboard equivalent for mouse drag scrolling beyond the arrow buttons
- Arrow buttons may be hidden on devices classified as mobile by the component's JavaScript touch/user-agent detection, including some iPads or other misclassified devices

> **Implementation note (for contributors):** The `<section>` and `<nav>` elements lack ARIA labels; there is no `role="region"` or live region on the scroll container itself. Arrow button visibility is controlled by a JavaScript mobile-detection check (`ontouchstart` plus a mobile/iPad user-agent match), not by viewport size or CSS breakpoints, so the limitation affects devices detected as mobile rather than all small screens.

## Server-rendered / CDN usage

ScrollContainer supports [layered hydration](https://github.com/unisdr/undrr-mangrove/blob/main/docs/HYDRATION.md). Use data attributes on a container element with server-rendered child content:

```html
<div
  data-mg-scroll-container
  data-height="300px"
  data-min-width="200px"
  data-item-width="250px"
  data-padding="16"
  data-show-arrows="true"
  data-stretch-items="true"
  data-step-size="300"
>
  <div class="mg-scroll__content">
    <div class="card">Card 1</div>
    <div class="card">Card 2</div>
  </div>
</div>
```

| Attribute            | Default   | Description                                       |
| -------------------- | --------- | ------------------------------------------------- |
| `data-height`        | `'auto'`  | Container height (CSS value)                      |
| `data-min-width`     | `'auto'`  | Minimum width (CSS value)                         |
| `data-item-width`    | `'auto'`  | Width for individual items (CSS value)            |
| `data-padding`       | `'0'`     | Container padding                                 |
| `data-show-arrows`   | `'false'` | Show navigation arrows (`'true'` or `'false'`)    |
| `data-stretch-items` | `'false'` | Stretch mixed-length items to a shared row height |
| `data-step-size`     | `null`    | Scroll step in pixels for arrow navigation        |

Child elements are extracted from a `.mg-scroll__content` wrapper inside the container. If no wrapper is found, the container's `innerHTML` is used directly.

```js
import createHydrator from 'https://assets.undrr.org/mangrove/2.0.0-alpha.4/components/hydrate.js';
import ScrollContainer, {
  fromElement,
} from 'https://assets.undrr.org/mangrove/2.0.0-alpha.4/components/ScrollContainer.js';
createHydrator({
  selector: '[data-mg-scroll-container]',
  component: ScrollContainer,
  fromElement,
});
```

See the [hydration guide](https://github.com/unisdr/undrr-mangrove/blob/main/docs/HYDRATION.md) for the full API and integration details.
