# Mega menu

The Mega Menu component provides a navigation menu with multiple levels and sections.

> **Note:** This component is currently in beta and subject to breaking changes in future releases.

## Usage

```jsx
import { MegaMenu } from '@components';

// Default (no logo)
<MegaMenu sections={menuItems} />

// Branded variant (with logo)
<MegaMenu
  sections={menuItems}
  logoSrc="https://assets.undrr.org/logos/pw/pw-logo.svg"
  logoAlt="PreventionWeb"
/>
```

### Multilingual sites and language-prefixed logo links

Pass the language-prefixed root path to `logoHref` (for example, `"/ar/"` for Arabic). In Drupal, output this from Twig into the `data-mg-mega-menu-logo-href` attribute:

```html
<div data-mg-mega-menu
     data-mg-mega-menu-logo-src="https://assets.undrr.org/logos/pw/pw-logo.svg"
     data-mg-mega-menu-logo-alt="PreventionWeb"
     data-mg-mega-menu-logo-href="/ar/">
</div>
```

`logoHref` defaults to `'/'` unless your CMS or wrapper provides a different value. If logo asset data attributes are not set, the Drupal wrapper resolves `logoSrc` and `logoAlt` from the page's body class (for example, `mg-current-domain--www-preventionweb-net`). `logoHref` is not inferred from the body class — it must be passed explicitly for language-prefixed URLs.

## Props

| Prop       | Type   | Default | Description                                                                                              |
| ---------- | ------ | ------- | -------------------------------------------------------------------------------------------------------- |
| sections   | array  | []      | Array of menu sections to display                                                                        |
| delay      | number | 300     | Delay in milliseconds before closing menu on mouse leave                                                 |
| hoverDelay | number | 180     | Delay in milliseconds before opening menu (prevents accidental opens)                                    |
| logoSrc    | string | —       | Image URL for the logo. When provided, enables the branded variant                                       |
| logoAlt    | string | ''      | Alt text for the logo image                                                                              |
| logoHref   | string | '/'     | Where the logo links to. For multilingual sites, pass the language-prefixed root from the CMS (e.g. `/ar/`) |
| logoWidth  | number | —       | Optional explicit width for CLS prevention                                                               |
| logoHeight | number | —       | Optional explicit height for CLS prevention                                                              |

### Section object properties

| Property         | Type   | Required | Description                                                         |
| ---------------- | ------ | -------- | ------------------------------------------------------------------- |
| title            | string | Yes      | Top-level menu item label                                           |
| icon             | string | No       | Icon class name shown before the title (e.g., `"mg-icon mg-icon-chart-bar"`). Desktop topbar only; hidden in mobile sidebar. |
| bannerHeading    | string | No       | Heading text shown in the mega content panel                        |
| bannerDescription| string | No       | Description text shown in the mega content panel                    |
| bannerButton     | object | No       | `{ url, label }` — when present, the top-level item renders as an `<a>` link |
| items            | array  | No       | Array of sub-items (triggers mega dropdown when present)            |

## Accessibility

### Keyboard navigation

- **Arrow Left / Arrow Right**: Moves focus between top-level menu items in the menu bar
- **Arrow Down**: On desktop, moves focus from a top-level item into its open submenu section
- **Tab / Shift+Tab**: Moves focus through focusable elements within an open submenu section
- **Escape**: Closes the mobile dialog and returns focus to the opener; on desktop, closes the open submenu panel
- Focus on a top-level item also triggers its submenu to open (via `onFocus`)

### ARIA attributes

- The root `<nav>` element has `aria-label="Main Navigation"`
- The top bar is a plain `<ul>` of links inside that labelled `<nav>`. It carries no `menubar` role: this is site navigation made of ordinary links, not an application menu, and `menubar` cannot legally contain the bar's hamburger button or its submenu panels
- Top-level items are ordinary links (or buttons where no URL is authored). Where a panel exists, `aria-expanded` announces it as a disclosure in both states
- Submenu panels use `role="region"` with `aria-live="polite"`, labelled by their own section title
- Each panel's category and submenu areas are `<nav>` landmarks named after their section (e.g. "About categories", "About submenu"), so a landmark list stays navigable when several sections are present
- Nested submenu lists use `role="menu"` with descriptive `aria-label` values (e.g., "Categories", "Submenu items")
- Nested links use `role="menuitem"` and `aria-haspopup` when they contain further sub-items
- Category links use `aria-current="page"` to indicate the currently highlighted category

### Mobile menu

- The opening button exposes `aria-expanded`, `aria-controls` and `aria-haspopup="dialog"`, with translated open/close labels.
- The bounded mobile menu uses `role="dialog"` and `aria-modal="true"`, labelled by the current level heading.
- Links and drill-in buttons use native navigation semantics. Tab and Shift+Tab stay within the open dialog, including controls in banner content; arrow keys retain native browser behaviour.
- Entering a level focuses its heading. Back restores the previous row and scroll position. Close and Escape restore the opener; resizing to desktop moves focus to a desktop navigation item.
- The closed dialog is hidden. Decorative desktop strip items become inert on mobile after hydration, keeping the full-strip opening target available.

### Branded variant

- When `logoSrc` is provided, the logo link has `aria-label` set to `logoAlt` (falling back to "Home")

### Known limitations

- On desktop, when a submenu closes via Escape or mouse leave, focus is not programmatically returned to the triggering menu item

## Server-rendered / CDN usage

MegaMenu supports [layered hydration](https://github.com/unisdr/undrr-mangrove/blob/main/docs/HYDRATION.md). This is a complex-tier component: in most integrations the `sections` prop comes from an API or server-side builder, not from static HTML. The `fromElement` function extracts timing props and an optional inline JSON sections attribute. Consumer wrappers typically override `sections`.

```html
<div data-mg-mega-menu
  data-delay="300"
  data-hover-delay="180"
  data-sections='[{"title":"About","items":[...]}]'>
</div>
```

| Attribute | Default | Description |
|-----------|---------|-------------|
| `data-delay` | `300` | Delay in ms before closing the menu on mouse leave |
| `data-hover-delay` | `180` | Delay in ms before opening the menu on hover |
| `data-sections` | — | JSON array of menu sections (optional; most consumers provide this via API) |
| `data-logo-src` | — | Logo image URL |
| `data-logo-alt` | `''` | Alt text for the logo image |
| `data-logo-href` | `'/'` | Where the logo links to (e.g., `/ar/` for language-prefixed root) |
| `data-logo-width` | — | Explicit width for CLS prevention |
| `data-logo-height` | — | Explicit height for CLS prevention |

> **Drupal note:** The Drupal wrapper reads prefixed attribute names (`data-mg-mega-menu-logo-src`, etc.) and falls back to a `SITE_LOGOS` body-class map when no logo attributes are set. CDN / vanilla HTML consumers use the short `data-logo-*` names above.

```js
import createHydrator from "https://assets.undrr.org/mangrove/2.0.0-alpha.4/components/hydrate.js";
import MegaMenu, { fromElement } from "https://assets.undrr.org/mangrove/2.0.0-alpha.4/components/MegaMenu.js";
createHydrator({ selector: "[data-mg-mega-menu]", component: MegaMenu, fromElement });
```

See the [hydration guide](https://github.com/unisdr/undrr-mangrove/blob/main/docs/HYDRATION.md) for the full API and integration details.

## Mobile progressive navigation

Below 900px, the existing navigation strip opens a bounded overlay menu. Each group
opens a new level on the same surface, with a labelled back button and a separate
Close action. Section headings link directly to their landing pages; there is no separate Overview link. Introductory
banner content appears directly beneath the links without an extra disclosure; desktop banners
remain unchanged. Returning restores the previous row focus and scroll position.
Escape and tapping the exposed page close the menu and return focus to the opener.
Back appears directly above the section title. The panel has a 400px minimum where
space permits, capped at the smaller of 700px or 90% of the dynamic viewport.
It uses a lightly translucent, blurred surface with an opaque fallback when blur
is unsupported. Reduced motion, reduced transparency, increased contrast and
forced colours use an opaque, unblurred surface without transitions. Normal
entry and exit use a short fade and sideways motion, mirrored in RTL. An exiting
panel becomes inert immediately and releases focus and page scrolling.

This is a drop-in update: existing `sections`, logo and timing props, Drupal
attributes and hydration entry points require no changes. The existing `labels`
object also accepts `backLabel`, `allSectionsLabel`, `closeLabel`, `overviewLabel`
and `toggleMobileNavLabel`; omitted keys use English defaults. The legacy `menuLabel` key remains accepted but is no longer displayed. Rich banner HTML
retains the existing caller-sanitised contract.

## Changelog

- **1.4.0** — 2026-09-10 ([#1114](https://github.com/unisdr/undrr-mangrove/issues/1114)): **Fixed:** the desktop top bar failed three axe rules whenever more than one section was present, which was never caught because the component's only axe assertion opened the mobile dialog first. The `menubar` role and its `menuitem`/`none` companions are gone — the bar is now a plain list of links inside the labelled `<nav>`, resolving `aria-required-children` (critical), and `aria-expanded` now reports both states on items that open a panel. Each section's landmarks are named after the section rather than sharing "Category navigation" and "Submenu content" (`landmark-unique`), and the category area is a `<nav>` element instead of an `<aside role="navigation">` (`aria-allowed-role`). Keyboard behaviour across the bar and into a panel is unchanged. The mobile hamburger is no longer clipped where the top bar is narrower than the viewport, such as a docs canvas or a constrained page: its overlay is anchored to the top bar rather than assumed to be `100vw`. A desktop-state axe assertion now covers the bar.

- **1.3.0** — 2026-09-08 ([#1099](https://github.com/unisdr/undrr-mangrove/issues/1099)): Added mobile progressive navigation with a consistent surface, explicit back and close actions, nested levels, linked section headings and preserved banner content, focus and scroll restoration, reduced motion and translated controls. Existing data and integration contracts remain supported. Authored content appears immediately, without a duplicate disclosure heading. The mobile hamburger is vertically centred without icon baseline spacing. Top-level sections use the shared semibold heading family; inner destinations use smaller regular body text and tighter spacing with 44px minimum targets. Forward chevrons distinguish entering a group from the Back arrow. Section headings remain compact and bold, with aligned text edges. Plain HTML Simple Nav removes the unused hamburger gutter and allows horizontal scrolling on mobile without markup changes. The redundant toolbar Menu label is omitted, leaving Close at the top right. Back sits above the title; the bounded translucent surface leaves an outside-dismiss area and uses RTL-aware fades with opaque accessibility-preference fallbacks.

- **1.2.6** — 2026-09-09 ([#1098](https://github.com/unisdr/undrr-mangrove/issues/1098)): **Fixed:** Arabic top-bar links were rendering in Roboto Condensed, which has no Arabic glyph coverage, because the component's `:lang(ar)` override named a class that does not exist ([#1095](https://github.com/unisdr/undrr-mangrove/issues/1095)). `.mg-mega-topbar__item-link` now reads the `ui` font role and resolves to Noto Sans Arabic. Latin rendering is unchanged.
