# Drawer

The `Drawer` component provides an accessible off-canvas drawer and floating panel for navigation, filters, settings, and secondary actions.

## Features

- **Positions**: `start` and `end` follow text direction (they swap in RTL), plus `bottom` for a sheet.
- **Variants**: a modal off-canvas drawer (with backdrop) or a non-modal floating panel (`isFloatingPanel`).
- **Accessibility**: `role="dialog"` named by the title, `aria-modal` while a backdrop drawer is open, focus moves to the close button on open, Tab stays inside a modal drawer, focus returns to the trigger on close, and Escape closes it. A closed drawer is `inert` and hidden, so its controls cannot be reached.
- **Content safety**: string `children` and `footer` render as plain text. Server-rendered markup goes through `bodyHtml` / `footerHtml`, which are sanitised with DOMPurify.
- **Translations**: the close button label comes from `labels.closeLabel`.

## Usage

### React

```jsx
import { Drawer } from '@undrr/undrr-mangrove';

<Drawer
  isOpen={isOpen}
  onClose={() => setIsOpen(false)}
  title="Filter options"
  position="start"
  labels={{ closeLabel: 'Close' }}
>
  <p>Drawer content goes here.</p>
</Drawer>;
```

### Drupal and server-rendered HTML (hydration)

Give the container an `id` and point one or more trigger buttons at it with `data-mg-drawer-trigger`:

```html
<button type="button" data-mg-drawer-trigger="filters">Filter options</button>

<div
  id="filters"
  data-mg-drawer
  data-position="start"
  data-title="Filter options"
  data-backdrop="true"
  data-is-open="false"
  data-close-label="Close"
>
  <div class="mg-drawer__body">
    <p>Server rendered drawer content.</p>
  </div>
  <div class="mg-drawer__footer">
    <button type="button" class="mg-button mg-button-primary">Apply</button>
  </div>
</div>
```

```js
import createHydrator from '@undrr/undrr-mangrove/components/hydrate.js';
import Drawer, {
  fromElement,
} from '@undrr/undrr-mangrove/components/Drawer.js';

createHydrator({
  selector: '[data-mg-drawer]',
  component: Drawer,
  fromElement,
});
```

The hydrated drawer keeps its own open state. Clicking a trigger toggles it and updates the trigger's `aria-expanded`. Scripts can also dispatch `mg-drawer:open`, `mg-drawer:close` or `mg-drawer:toggle` on the container.

| Attribute                | Default   | Description                                                            |
| ------------------------ | --------- | ---------------------------------------------------------------------- |
| `id`                     | —         | Required for `data-mg-drawer-trigger` buttons to find the drawer       |
| `data-position`          | `'start'` | Drawer edge placement (`'start'`, `'end'`, `'bottom'`)                 |
| `data-title`             | —         | Drawer header title text                                               |
| `data-backdrop`          | `'true'`  | Whether to render the semi-transparent backdrop (`'true'` / `'false'`) |
| `data-is-floating-panel` | `'false'` | Whether to render as a floating panel                                  |
| `data-is-open`           | `'false'` | Initial open state                                                     |
| `data-close-label`       | `'Close'` | Translated close button label                                          |
