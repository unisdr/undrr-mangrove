# Snackbar

Brief notifications or feedback messages about an operation's status. Appears temporarily at the top of the screen and automatically disappears after a set time.

The toast body is a [Notice](?path=/docs/components-notice-notice--docs), so severities share Notice's colours, icons and spacing: `error` maps to `negative`, `success` to `positive`.

## Features

- **Multiple severity levels** — Error, warning, info, success with appropriate icons and colors
- **Automatic dismissal** — Disappears after configurable time
- **Manual dismissal** — Close button available
- **Keyboard accessible** — Dismissible with Escape key
- **Screen reader support** — ARIA attributes for announcements
- **Responsive** — Works on desktop and mobile

## How to use

### Basic implementation

```jsx
import React, { useState } from 'react';
import Snackbar from './path/to/Snackbar';

function MyComponent() {
  const [isOpen, setIsOpen] = useState(false);

  const handleClose = () => {
    setIsOpen(false);
  };

  return (
    <div>
      <button onClick={() => setIsOpen(true)}>Show Notification</button>

      <Snackbar
        severity="info"
        opened={isOpen}
        message="This is an informational message"
        onClose={handleClose}
        openedMiliseconds={5000}
      />
    </div>
  );
}
```

## Component props

| Prop              | Type     | Default | Description                                                                       |
| ----------------- | -------- | ------- | --------------------------------------------------------------------------------- |
| severity          | string   | —       | Appearance and icon: 'error', 'warning', 'info', 'success'                        |
| opened            | boolean  | false   | Controls visibility                                                               |
| message           | string   | —       | Text content to display                                                           |
| onClose           | function | —       | Callback when closed (button click or timeout)                                    |
| openedMiliseconds | number   | —       | Duration before auto-closing. If not provided, remains open until manually closed |

## Accessibility

- `error` and `warning` toasts use `role="alert"` (assertive); `info` and `success` use `role="status"` (polite). The body is mounted only while open, so it is announced when it appears and is not duplicated by an `aria-live` wrapper
- Announces severity for screen readers
- While closed there is no off-screen close button in the tab order
- Dismissible with Escape key
- A persistent toast (no `openedMiliseconds`) moves focus to its close button; an auto-dismissing toast leaves focus where it is, so it cannot vanish from under the reader
- On close, focus returns to the element that had it before the toast opened
- While sliding out, the toast is `aria-hidden` and inert, then unmounted

## Mobile considerations

- Responsive layout adapts to smaller screens
- Close button uses the standard `.mg-button` sizing
- Proper spacing for mobile viewports

The body mounts only while open (staying hidden and inert through the slide-out), focus returns to its previous element on close, auto-dismissing toasts no longer take focus, and the redundant `aria-live` wrapper is gone. The props API is unchanged; `severity` now defaults to `info`, and `info`/`success` toasts announce politely (`role="status"`) instead of as alerts.
