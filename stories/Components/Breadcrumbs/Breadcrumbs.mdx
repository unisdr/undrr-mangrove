# Breadcrumbs

Breadcrumbs show the current page location and provide links back through
parent pages. The component generates links from pathname/config with minimal
setup.

## When to use

- Show where the current page sits and let users move back up the hierarchy.

## Formatting

Links are separated by a CSS chevron separator rendered via `::before`. The final item represents the current page and is rendered as plain text rather than a link.

## Default

The breadcrumb appears below the main navigation bar.

## States

The component renders in a single **default** state. The current-page item receives `aria-current="page"` and is not interactive.

<Canvas of={BreadcrumbsStories.DefaultBreadcrumbs} meta={BreadcrumbsStories} />

## Usage

```html
<nav aria-label="Breadcrumb">
  <ol class="mg-breadcrumb">
    <li class="mg-breadcrumb__item"><a href="/">Home</a></li>
    <li class="mg-breadcrumb__item"><a href="/section">Section</a></li>
    <li class="mg-breadcrumb__item" aria-current="page">Current page</li>
  </ol>
</nav>
```

The final item receives `aria-current="page"` and renders as plain text (not a link).

## Interactions

- Clicking a breadcrumb link navigates to that ancestor page.
