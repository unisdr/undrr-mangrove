# ShareButtons

A widget with share buttons for social media that open new tabs or copy the link to clipboard.

## Overview

Clickable share buttons for LinkedIn, Facebook, Twitter, Email, and QR code. Includes a copy-to-clipboard option and optional QR code modal with UTM parameters.

## Configuration

- **Default body**: "Check out this link: " + URL
- **Default subject**: "Sharing Link"
- Custom message body and subject can be configured

### Shortlink preference

The component uses shortlinks when a `<link rel="shortlink" href="{url here}" />` is present. Defaults to the full page URL if unavailable.

## Behaviors

- Clicking a social button opens a new tab with the sharing link
- Clicking the copy button copies the link to clipboard
- Clicking the QR code button opens a modal with:
  - QR code image
  - URL with UTM tracking parameters
  - Guidance text and copy/close options

## Server-rendered usage

ShareButtons supports hydration from server-rendered HTML using `createHydrator` and the bundled `fromElement` function. This is how the component is integrated in Drupal and other server-rendered frameworks.

The server renders a container with localized labels as data attributes:

```html
<section
  data-mg-share-buttons
  data-main-label="Share this"
  data-on-copy-label="Link copied"
  data-sharing-subject="Sharing Link"
  data-sharing-body="Check out this link: "
></section>
```

The client script mounts the React component in three lines:

```js
import createHydrator from './hydrate.js';
import ShareButtons, { fromElement } from './ShareButtons.js';
createHydrator({
  selector: '[data-mg-share-buttons]',
  component: ShareButtons,
  fromElement,
});
```

`fromElement` extracts labels and sharing config from data attributes, with sensible English defaults for any missing attributes.

See the [Hydration guide](https://github.com/unisdr/undrr-mangrove/blob/main/docs/HYDRATION.md) for the full API and integration details.
