# Chips

Compact pill-shaped controls used for category navigation and active filters. The pill shape is intentional: it distinguishes a chip from conventional actions and form controls.

## When to use

- Show active filters or search terms
- Let users remove individual selections
- Link to related content categories/tags

## States

**Category link** — Navigates to related content; use the default variant with a meaningful `href`.

**Dismissible filter** — Single button with visible × that removes the filter.

**Hover, focus, pressed** — Surface changes on hover; keyboard focus uses shared token-driven focus ring; reduced-motion-aware subtle press feedback.

Labels can grow without clipping the dismissal mark. Logical spacing keeps the mark on the correct trailing edge in both directions.

## Usage

### Category link

```html
<a class="mg-chip" href="/topics/climate-risk">Climate risk</a>
```

### Dismissible filter

```html
<button
  class="mg-chip mg-chip__cross"
  type="button"
  aria-label="Remove filter: Earthquake"
>
  Earthquake
</button>
```

Copy from the HTML tab in the canvas above for the full rendered output with any additional wrapper classes.

## Interactions

- Category chips follow their link when activated.
- The entire dismissible chip is one button and removes its filter when activated.
- Consumers handle removal through `onDismiss`; Mangrove does not mutate the surrounding filter collection.

## Accessibility

- The dismissal mark is decorative; provide a localized action name with `removeLabel` (e.g., "Remove filter: Sendai Framework")
- Keyboard users activate dismiss with **Enter** or **Space**
- Move focus to the next chip or related input after dismissal
- Interactive chips provide 40px targets and preserve explicit boundaries in forced-colors mode
