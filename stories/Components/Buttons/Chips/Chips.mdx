# Chips

Compact pill-shaped controls used for category navigation and active filters. The pill shape is intentional: it distinguishes a chip from conventional actions and form controls.

## When to use

- Showing which filters or search terms are currently active
- Letting users remove individual selections without clearing everything
- Linking to a category or tag in a content listing

## States

**Category link** — The chip navigates to related content. Use the default variant and provide a meaningful `href`.

**Dismissible filter** — The chip is a single button with a visible ×. Activating any part of the button removes the filter or selection.

**Hover and focus** — The surface changes on hover, while keyboard focus uses the shared token-driven focus ring.

**Pressed** — The chip uses the shared subtle press feedback when reduced motion is not requested.

## Usage

### Category link

```html
<a class="mg-chip" href="/topics/climate-risk">Climate risk</a>
```

### Dismissible filter

```html
<button
  class="mg-chip mg-chip__cross"
  type="button"
  aria-label="Remove filter: Earthquake"
>
  Earthquake
</button>
```

Copy from the HTML tab in the canvas above for the full rendered output with any additional wrapper classes.

## Interactions

- Category chips follow their link when activated.
- The entire dismissible chip is one button and removes its filter when activated.
- Consumers handle removal through `onDismiss`; Mangrove does not mutate the surrounding filter collection.

## Accessibility

- The dismissal mark is decorative because the visible label is part of the same button. Provide a localised action name with `removeLabel`, such as `Remove filter: Sendai Framework`.
- Keyboard users activate the dismiss button with **Enter** or **Space**.
- After a chip is dismissed, move focus to the next chip or the related search input — do not drop focus.
- Interactive chips provide a 40px target and preserve explicit boundaries in forced-colours mode.
