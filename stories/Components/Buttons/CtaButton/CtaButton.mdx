# Buttons

Mangrove's standard button component for call-to-action elements like "Read more", "Sign up", or "View documentation."

## When to use

- Drive specific user actions (use links for page navigation)
- One primary action per page; secondary/tertiary should be sparse
- For multiple choices, mark one as primary and others secondary/tertiary

#### Variants

| Class                                              | Purpose                                                    |
| -------------------------------------------------- | ---------------------------------------------------------- |
| `.mg-button.mg-button-primary`                     | Main call to action — filled background, high contrast     |
| `.mg-button.mg-button-secondary`                   | Supporting action — lower visual weight than primary       |
| `.mg-button.mg-button-primary.mg-button-outline`   | Primary emphasis with a transparent surface                |
| `.mg-button.mg-button-secondary.mg-button-outline` | Secondary emphasis with a transparent surface              |
| `.mg-button.mg-button-primary.mg-button-cta`       | Editorial navigation with a circular direction badge       |
| `.mg-button.mg-button-{variant}.mg-button--icon`   | Compact square icon-only button (toolbars, map actions)    |
| `.mg-button--icon--round`                          | Added to the row above: circular floating action button    |
| `.mg-button--icon--small`                          | Added to the row above: dense 28px toolbar icon button     |
| `.mg-button--responsive-icon`                      | Icon + text on desktop, collapses to icon-only on mobile   |
| `.mg-icon-button`                                  | Standalone ghost icon button — takes no other button class |
| `.mg-icon-button--round`, `.mg-icon-button--small` | Circular and 28px variants of the standalone ghost button  |
| `.mg-button.disabled`                              | Inactive state — not clickable                             |

## Content

- Use clear, action-oriented labels: "Download report", "Sign up" (not "Click here")
- Keep labels to 2–3 words

## Buttons with icons

Icons help users recognize frequent actions (download, search, share, filter) faster.

### Icon with text label

When a visible text label is present, the icon is purely decorative and must have `aria-hidden="true"`. The button derives its accessible name directly from the visible text:

```html
<button type="button" class="mg-button mg-button-primary">
  <span class="mg-icon mg-icon-download" aria-hidden="true"></span>
  <span>Download report (PDF)</span>
</button>
```

```jsx
<button type="button" className="mg-button mg-button-primary">
  <Icon name="download" />
  <span>Download report (PDF)</span>
</button>
```

<Canvas of={CtaButtonStories.IconWithLabel} meta={CtaButtonStories} />

### Icon-only buttons

Compact square (`.mg-button--icon`), circular (`.mg-button--icon--round`), and dense toolbar (`.mg-button--icon--small`) buttons for actions without visible text labels (e.g. toolbars, map controls, modal close buttons).

```html
<button
  type="button"
  class="mg-button mg-button-primary mg-button--icon"
  aria-label="Search publications"
>
  <span class="mg-icon mg-icon-search" aria-hidden="true"></span>
</button>
```

### Two icon-only classes, and which one to use

There are two of them, and they are not interchangeable.

| Use                                                                | Class                                                      | Colour                                            |
| :----------------------------------------------------------------- | :--------------------------------------------------------- | :------------------------------------------------ |
| An icon-only button in a brand colour                              | `.mg-button` + `.mg-button-{variant}` + `.mg-button--icon` | From the variant, exactly like a text button      |
| A borderless control on an existing surface (dismiss, close, copy) | `.mg-icon-button` on its own                               | Transparent, inherits the surrounding text colour |

`.mg-button--icon` is a shape modifier: it makes a `.mg-button` square and centres the icon, and everything else — foreground colour, typography, focus ring — still comes from `.mg-button`. Use it whenever the button should carry a variant colour.

`.mg-icon-button` is a standalone primitive with the same geometry plus its own reset, hover and focus ring. It is what Notice's dismiss control and Drawer's close control use. It deliberately carries no variant colours, so **do not add `.mg-button-primary`, `.mg-button-secondary` or `.mg-button-outline` to it** — those classes only paint a background, and the readable foreground that goes with them lives on `.mg-button`, which a `.mg-icon-button` never has. Since 1.5.2 the filled combination is caught by a contrast guard rather than rendering a dark glyph on the fill, but it is still the wrong markup: `.mg-button-outline` still draws no border on it, and nothing else `.mg-button` provides is there.

```html
<!-- Wrong: .mg-icon-button takes no variant classes -->
<button
  type="button"
  class="mg-icon-button mg-button-primary mg-icon-button--round"
>
  …
</button>

<!-- Right: a variant-coloured round icon button -->
<button
  type="button"
  class="mg-button mg-button-primary mg-button--icon mg-button--icon--round"
  aria-label="Add a record"
>
  <span class="mg-icon mg-icon-circle-plus" aria-hidden="true"></span>
</button>

<!-- Right: a ghost control on an existing surface -->
<button
  type="button"
  class="mg-icon-button mg-icon-button--small"
  aria-label="Dismiss"
>
  <span class="mg-icon mg-icon-close" aria-hidden="true"></span>
</button>
```

A bare `.mg-icon-button` is a borderless ghost button that can sit on its own or inline within text.

### Responsive icon buttons

For toolbars and headers where screen space is tight on mobile, use `.mg-button--responsive-icon` with a child `<span class="mg-button__label">`. On tablet and desktop, the button displays both the icon and text label. On mobile screens (`< 768px`), it automatically collapses to a compact 36&times;36px icon-only square button while preserving the full text label in the DOM for screen readers.

```html
<button
  type="button"
  class="mg-button mg-button-primary mg-button--responsive-icon"
>
  <span class="mg-icon mg-icon-search" aria-hidden="true"></span>
  <span class="mg-button__label">Search publications</span>
</button>
```

## Accessibility guidelines for icon buttons

| Pattern                 | Markup Technique                                                                   | Screen Reader Announcement         | WCAG Compliance                                                   |
| :---------------------- | :--------------------------------------------------------------------------------- | :--------------------------------- | :---------------------------------------------------------------- |
| **Icon + visible text** | Visible `<span>Label</span>`, `<span class="mg-icon *" aria-hidden="true"></span>` | Reads visible text directly        | ✅ WCAG 2.5.3 (Label in Name) — DO NOT add redundant `aria-label` |
| **Icon-only**           | `aria-label="Action description"`, `<span class="mg-icon *" aria-hidden="true">`   | Reads `aria-label` attribute       | ✅ WCAG 4.1.2 (Name, Role, Value) — `aria-label` is mandatory     |
| **Responsive icon**     | `<span class="mg-button__label">Label</span>`                                      | Reads clipped label on all screens | ✅ WCAG 2.5.3 & 4.1.2 — seamless across mobile and desktop        |

> **Target size notice:** The `--small` variant (28 &times; 28px) meets the WCAG 2.5.8 minimum target size (24px) but not the enhanced target (44px); use it only in dense toolbars where surrounding spacing provides the necessary hit area.

## Usage

- Apply `.mg-button` as the base class, then add an emphasis class (`.mg-button-primary` or `.mg-button-secondary`)
- Add `.mg-button-outline` for unfilled treatment
- For an icon-only button in a brand colour, keep `.mg-button` and add `.mg-button--icon`; `.mg-icon-button` is a separate standalone primitive and takes no `.mg-button-*` class
- Wrap adjacent actions in `.mg-buttons` for consistent, RTL-safe spacing (don't add margins to individual buttons)
- Copy HTML from the HTML tab in the canvas

## Interactions

- Hover state applies to the entire button
