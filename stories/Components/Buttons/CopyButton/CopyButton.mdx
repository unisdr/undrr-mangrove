# Copy button

The `CopyButton` allows users to quickly copy a string to their clipboard, featuring a visual micro-feedback tooltip and accessible status announcements via `aria-live`.

## Integration options

Mangrove offers three integration paths depending on your project setup:

### Option 1: Standalone Vanilla JS (Zero React Dependency)

For Drupal Twig templates, static HTML pages, or server-rendered layouts where React is not used, load the standalone script `@undrr/undrr-mangrove/js/copy-button.js` (or `dist/js/copy-button.min.js`). It automatically initializes all `[data-mg-copy-button]` elements on the page.

```html
<button
  type="button"
  class="mg-button mg-button-primary mg-button-outline mg-button--icon mg-copy-button"
  data-mg-copy-button
  data-text-to-copy="https://preventionweb.net/drr-glossary"
  data-aria-label="Copy glossary link"
  data-tooltip-label="Copied!"
>
  <span class="mg-icon mg-icon-copy mg-button__icon" aria-hidden="true"></span>
  <span class="mg-copy-button__feedback" role="status" aria-hidden="true">
    Copied!
  </span>
  <span class="mg-u-sr-only" aria-live="polite"></span>
</button>

<!-- Standalone vanilla UMD script -->
<script src="dist/js/copy-button.min.js"></script>
```

In Drupal behaviors or SPAs, you can manually re-initialize dynamically inserted content:

```js
import { mgCopyButton } from '@undrr/undrr-mangrove/js/copy-button.js';

Drupal.behaviors.copyButton = {
  attach(context) {
    mgCopyButton(context);
  },
};
```

<Canvas of={CopyButtonStories.VanillaHtmlLiveIntegration} />

### Option 2: Layer 2 React Hydration (`createHydrator`)

If your Drupal site uses Mangrove's shared React hydration runtime with import maps:

```js
import createHydrator from '@undrr/undrr-mangrove/hydrate';
import CopyButton, {
  fromElement,
} from '@undrr/undrr-mangrove/components/CopyButton';

createHydrator({
  selector: '[data-mg-copy-button]',
  component: CopyButton,
  fromElement,
});
```

### Option 3: React JSX Component

In React applications:

```jsx
import { CopyButton } from '@undrr/undrr-mangrove';

<CopyButton
  textToCopy="https://preventionweb.net/drr-glossary"
  ariaLabel="Copy glossary link"
  variant="outline"
/>;
```

## Data attributes reference

| Attribute            | Default                  | Description                                                   |
| -------------------- | ------------------------ | ------------------------------------------------------------- |
| `data-text-to-copy`  | `''`                     | Text string to be written to the clipboard                    |
| `data-aria-label`    | `'Copy to clipboard'`    | Accessible button name for screen readers                     |
| `data-tooltip-label` | `'Copied!'`              | Text displayed inside the transient micro-feedback badge      |
| `data-copied-label`  | `'Copied to clipboard.'` | Text announced to `aria-live` upon successful copy            |
| `data-variant`       | `'outline'`              | Button visual style (`'outline'`, `'primary'`, `'secondary'`) |
| `data-size`          | `—`                      | Button icon size (`'small'`, `'large'`)                       |
