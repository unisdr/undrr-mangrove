# Typography integration

## Arabic tracking

The shared script profile in `_fonts.scss` applies `letter-spacing: normal`
to Arabic elements and their generated labels, including inherited languages
and regional tags such as `ar-SA`. It is intentionally important so later
component declarations cannot break joining. Set `lang` at language boundaries:
`dir="rtl"` alone does not identify a script. Explicit English islands keep
their component tracking; unmarked text inherits its surrounding language.

See the existing [language-boundary examples](?path=/story/design-decisions-language-boundaries--arabic-page-with-latin-island) for mixed-language content.
