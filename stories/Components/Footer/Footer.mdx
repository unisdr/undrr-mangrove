# Footer

> **Note:** This component is in beta and will evolve as Mangrove and Syndication become more integrated.

The Footer component wraps the UNDRR Syndication feature's JavaScript, combining site-specific content with UNDRR's global syndicated footer for consistent UNDRR branding across network sites.

## Overview

Add site-specific content (social links, org descriptions, or site info) above the automatically-loaded UNDRR footer. For page-level feedback, place the standalone [`UserFeedback`](?path=/docs/components-user-feedback--docs) component immediately before `Footer` as a sibling—don't nest them.

### When to use

- **Network sites** needing consistent UNDRR footer content
- **Organization pages** adding their own footer information
- **Landing pages** combining local and global footer elements

## Features

### UNDRR syndication integration

The footer automatically loads content from the UNDRR syndication system using the PreventionWeb widget:

```jsx
<Footer
  enableSyndication={true}
  syndicationConfig={{
    contenttype: 'landingpage',
    pageid: '83835',
    includemetatags: false,
    includecss: false,
    suffixID: 'footer',
    activedomain: 'www.undrr.org',
  }}
/>
```

### Complementary content support

Add your own footer content using `complementaryContent` or `children`:

```jsx
<Footer>
  <section className="site-footer">
    <p>Your organization's footer content here</p>
  </section>
</Footer>
```

### Configuration options

| Prop                   | Type      | Default     | Description                                                                         |
| ---------------------- | --------- | ----------- | ----------------------------------------------------------------------------------- |
| `variant`              | string    | `"default"` | Visual variant (`"default"` or `"minimal"`)                                         |
| `enableSyndication`    | boolean   | `true`      | Enable/disable UNDRR syndicated content                                             |
| `syndicationConfig`    | object    | See below   | Configuration for the syndication widget (partial configs are merged with defaults) |
| `complementaryContent` | ReactNode | `null`      | Site-specific content to display above syndicated footer                            |
| `children`             | ReactNode | `null`      | Alternative way to pass complementary content                                       |

#### Default syndication configuration:

```javascript
{
  contenttype: 'landingpage',
  pageid: '83835',
  includemetatags: false,
  includecss: false,
  suffixID: 'footer',
  activedomain: 'www.undrr.org'
}
```

## Interactions

- Syndicated content loads automatically after component mounts
- Links in complementary content work as standard anchor tags
- Error handling displays fallback if syndication fails
- Loading states provide visual feedback

## Utility footer bar

> **Note:** This is new and may change as DELTA and other sub-branded sites evolve.

The `mg-footer-bar` is a CSS-only utility component for secondary navigation below the main footer, used by sub-branded sites for product links, disclaimers, and legal information.

```html
<footer class="mg-footer-bar">
  <div class="mg-container">
    <div class="mg-footer-bar__row">
      <div class="mg-footer-bar__links">
        <strong>DELTA</strong>
        <a href="/help">Help</a>
        <a href="/report-bug">Report a bug</a>
      </div>
    </div>
    <hr class="mg-footer-bar__divider" />
    <div class="mg-footer-bar__row">
      <p class="mg-footer-bar__text">Descriptive text about the sub-brand.</p>
      <div class="mg-footer-bar__links">
        <a href="/privacy">Privacy policy</a>
        <a href="/terms">Terms and conditions</a>
      </div>
    </div>
  </div>
</footer>
```

### BEM elements

| Element                  | Description                             |
| ------------------------ | --------------------------------------- |
| `mg-footer-bar__row`     | Flex row with space-between alignment   |
| `mg-footer-bar__links`   | Inline link group with gap spacing      |
| `mg-footer-bar__text`    | Descriptive paragraph (max-width 600px) |
| `mg-footer-bar__divider` | Horizontal rule separator               |

## Syndication loading

### JavaScript approach

The component uses a simplified JavaScript approach that injects required scripts:

```html
<!-- Widget loader script -->
<script
  type="text/javascript"
  src="https://publish.preventionweb.net/widget.js?rand=3d797b"
></script>

<!-- Widget initialization -->
<script>
  new PW_Widget.initialize({
    contenttype: 'landingpage',
    pageid: '83835',
    includemetatags: false,
    includecss: false,
    suffixID: 'footer',
    activedomain: 'www.undrr.org',
  });
</script>
```

This approach automatically handles CSS loading when `includecss` is set to `true`, eliminating manual stylesheet management.

#### Partial configuration support

Provide only the options you want to override; the component merges them with defaults:

```jsx
// Override suffixID only, keep other defaults
<Footer syndicationConfig={{ suffixID: 'my-footer' }} />

// Override multiple options
<Footer syndicationConfig={{ pageid: '12345', suffixID: 'special-footer', includecss: true }} />
```

### Site integration

Typical site footer implementation:

```jsx
<Footer
  complementaryContent={
    <section className="site-footer">
      <div className="container">
        <p className="social-links">
          <a href="https://facebook.com/yourorg">Facebook</a>
          <a href="https://twitter.com/yourorg">Twitter</a>
        </p>
        <p className="org-description">Your organization's mission statement.</p>
      </div>
    </section>
  }
/>
```
