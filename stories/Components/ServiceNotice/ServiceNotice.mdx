# Service notice

An in-page notice or card overlay shown when an embedded third-party service (such as MapX, an external analytics feed, or an API endpoint) is unreachable or running in a degraded state.

It shows a degraded or offline status badge, an explanation, a retry action, a link to an external status page, and optional automatic retries. It renders through the [Notice](/docs/components-notice-notice--docs) component, so it inherits its layout, tokens, compact and overlay modifiers.

## Automatic retry

Set `countdownSeconds` together with `onRetry` to retry automatically. After each attempt the wait doubles (for example 15s, 30s, 60s), and after `maxAutoRetries` attempts (default 3) the countdown stops and only the manual retry button remains. This keeps a hard outage from being polled indefinitely.

When the service recovers, remove the notice. Changing `countdownSeconds` starts a new retry cycle.

## Integration

### 1. Pure HTML / CSS

```html
<div class="mg-notice mg-notice--warning">
  <div class="mg-notice__header">
    <span
      class="mg-icon mg-icon-exclamation-triangle mg-notice__icon"
      aria-hidden="true"
    ></span>
    <h3 class="mg-notice__title">MapX layer service degraded</h3>
    <span class="mg-status-label mg-status-label--warning">
      <span class="mg-status-label__indicator" aria-hidden="true"></span>
      Degraded
    </span>
  </div>
  <div class="mg-notice__description">
    <p>
      Geospatial tiles are taking longer than usual to render. Cached layers
      remain accessible.
    </p>
  </div>
  <div class="mg-notice__actions mg-buttons">
    <button type="button" class="mg-button mg-button-primary">
      <span
        class="mg-icon mg-icon-refresh mg-button__icon"
        aria-hidden="true"
      ></span>
      Retry connection
    </button>
    <a
      href="https://status.undrr.org"
      target="_blank"
      rel="noopener noreferrer"
      class="mg-button mg-button-secondary mg-button-outline"
    >
      View status page
      <span
        class="mg-icon mg-icon-external-link mg-button__icon"
        aria-hidden="true"
      ></span>
    </a>
  </div>
</div>
```

The markup is a [Notice](/docs/components-notice-notice--docs) with a [StatusLabel](/docs/components-status-label--docs) in its header; there is no separate `mg-service-notice` stylesheet. A retry countdown uses `mg-notice__meta` inside the actions row. The offline state swaps in `mg-notice--negative`, `mg-icon-power-off` and `mg-status-label--negative`. Static HTML should announce the outage itself if it is injected after page load (for example with a `role="status"` region).

### 2. Drupal Twig with React hydration

```twig
<div data-mg-service-notice
  data-title="{{ 'MapX service unreachable'|t }}"
  data-description="{{ 'Unable to establish a secure connection to the map tile server.'|t }}"
  data-status="offline"
  data-retry
  data-retry-label="{{ 'Reconnect'|t }}"
  data-status-url="https://status.undrr.org"
  data-status-url-label="{{ 'Check status'|t }}"
  data-countdown-seconds="30"
  data-max-auto-retries="3">
</div>
```

```javascript
import createHydrator from '@undrr/undrr-mangrove/src/hydrate';
import ServiceNotice, {
  fromElement,
} from '@undrr/undrr-mangrove/stories/Components/ServiceNotice/ServiceNotice.hydrate';

const hydrator = createHydrator({
  selector: '[data-mg-service-notice]',
  component: ServiceNotice,
  fromElement,
});

Drupal.behaviors.mangroveServiceNotice = {
  attach(context) {
    hydrator.update(context);
    context.querySelectorAll?.('[data-mg-service-notice]').forEach(el => {
      el.addEventListener('mg-service-notice:retry', () => reloadMapEmbed());
    });
  },
};
```

With `data-retry` present, the retry button and every automatic retry dispatch a bubbling `mg-service-notice:retry` event on the container. Without `data-retry`, no retry button or countdown is rendered. Title and description are read as plain text.

### 3. React component

```jsx
import { ServiceNotice } from '@undrr/undrr-mangrove';

function MapWidget() {
  return (
    <div style={{ position: 'relative', height: '400px' }}>
      <ServiceNotice
        title="Map service temporarily unavailable"
        description="The tile server returned 503. Interactive features are disabled."
        status="offline"
        isOverlay
        onRetry={() => refetchLayers()}
        statusUrl="https://status.undrr.org"
        countdownSeconds={15}
        maxAutoRetries={3}
      />
    </div>
  );
}
```

## Accessibility

- The component includes a visually hidden `role="status"` region. It is filled just after mount, so the status and title are announced even when the notice appears already populated (for example as an overlay). It is updated again when an automatic retry is scheduled and when automatic retries stop.
- The visible countdown is `aria-hidden`, because announcing every second would drown out everything else. Screen reader users hear "Retrying automatically in N seconds" once per attempt instead.
- The status badge pairs a coloured dot with visible text (Degraded / Offline), satisfying WCAG 2.2 SC 1.4.1 (Use of Color).
- The status page link opens in a new tab with `rel="noopener noreferrer"`.
- `headingLevel` lets the title fit the page's heading outline instead of forcing `h3`.

## Translations
