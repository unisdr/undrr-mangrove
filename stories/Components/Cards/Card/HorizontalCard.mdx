# Horizontal card

A content teaser card in landscape/side-by-side layout. Image on the left, text on the right. Well suited for content-heavy listings where the image is secondary.

## When to use

- List-style content pages (search results, filtered listings)
- Layouts where vertical space is limited and horizontal reading flow is preferred
- Content with longer titles or summaries that benefit from a wider text area

## Anatomy

- **Image**: Displayed at left on desktop (160px or 330px wide), stacked on top on mobile (300px tall)
- **Labels**: Content type or category tags
- **Title**: Linked heading with blue color, underline, and chevron indicator
- **Summary**: Body text, supports inline HTML links
- **CTA button**: Primary action button

The entire card is clickable via a stretched link on the title.

## Color variants

Use the `variant` prop to change the title accent color. These match the Hero component color system and adapt per theme.

| Variant             | Class                 | Color                          |
| ------------------- | --------------------- | ------------------------------ |
| `primary` (default) | —                     | `$mg-color-interactive` (blue) |
| `secondary`         | `mg-card--secondary`  | `$mg-color-secondary` (orange) |
| `tertiary`          | `mg-card--tertiary`   | `$mg-color-tertiary` (black)   |
| `quaternary`        | `mg-card--quaternary` | `$mg-color-quaternary` (red)   |

Use the variant control below the canvas to preview each option.

## Title link visibility

By default, card titles display three signals that they are clickable:

1. **Blue color** matching the theme's interactive color (adapts per theme)
2. **Underline** with a 3px offset
3. **Chevron indicator** pointing right (flips left automatically in RTL layouts)

On hover, the underline intensifies.

### Opting out

Add `mg-card--plain-title` to disable all link signals while keeping the card clickable.

**In React:**

```jsx
<HorizontalCard data={data} className="mg-card--plain-title" />
```

**In Drupal templates or static HTML:**

```html
<article class="mg-card mg-card__hc mg-card--plain-title">...</article>
```

> **Implementation note (for contributors):** The chevron is a CSS border triangle rendered via the `::after` pseudo-element on the title link. On hover, the underline stroke increases to `2px`. RTL flipping is applied via a `[dir="rtl"]` CSS selector.

## Responsive behavior

| Breakpoint        | Layout                                                   |
| ----------------- | -------------------------------------------------------- |
| Mobile (< 640px)  | Stacked: image on top (300px tall), content below        |
| Tablet (640px+)   | Side-by-side: 160px image, content fills remaining width |
| Desktop (1024px+) | Side-by-side: 330px image, content fills remaining width |

## Cards without links

A card should almost always be a link, but unlinked ones happen: an editor leaves the link field empty, a referenced node is unpublished, or the card exists only to carry a button.

Omit `link` (or pass an empty string) and the card renders its title as plain text — no chevron, no underline, no interactive colour, no stretched click target, no hover elevation. Labels stay visible but drop the interactive modifier. The article gains `mg-card--no-link` so themes have a hook.

<Canvas of={HorizontalCardStories.NoLinkHorizontalCard} />

### A button instead of a card link

For a card whose only destination is its button, set `buttonLink` and leave `link` empty. The title stays plain text and the CTA is an ordinary in-flow link. `buttonLink` falls back to `link` when omitted, so existing cards are unaffected.

<Canvas of={HorizontalCardStories.ButtonOnlyHorizontalCard} />

Drupal Gutenberg emits `<a href="">` for unlinked cards, which a browser treats as a link to the current page: it takes focus, activating it reloads the page, and the stretched overlay swallows clicks aimed at the card's own button. `card.scss` neutralises that markup so published content is repaired without an upstream change, but CSS cannot take the anchor out of the tab order — emit a plain-text title at the source.

See [Vertical card](?path=/docs/components-cards-vertical-card--docs#cards-without-links) for the full rationale and the `href=""` reference case.

## Props

| Prop        | Type   | Default     | Description                                                             |
| ----------- | ------ | ----------- | ----------------------------------------------------------------------- |
| `data`      | Array  | Required    | Array of card data objects                                              |
| `variant`   | String | `'primary'` | Color variant: `'primary'`, `'secondary'`, `'tertiary'`, `'quaternary'` |
| `className` | String | —           | Additional CSS classes on the card element                              |

### Data object properties

| Property      | Type   | Description                                                                                             |
| ------------- | ------ | ------------------------------------------------------------------------------------------------------- |
| `title`       | String | Card heading text                                                                                       |
| `link`        | String | URL for the title link and stretched link. Omit it, or pass an empty string, to render an unlinked card |
| `imgback`     | String | Image URL                                                                                               |
| `imgalt`      | String | Alt text for the image                                                                                  |
| `summaryText` | String | Body text (HTML supported)                                                                              |
| `label1`      | String | First category label                                                                                    |
| `label2`      | String | Second category label                                                                                   |
| `button`      | String | CTA button label                                                                                        |
| `buttonLink`  | String | CTA destination. Defaults to `link`; set it to give an unlinked card a button                           |
