# Stats card

A flexible component for displaying statistics and key metrics in an engaging, scannable format.

## Overview

Displays statistics and metrics in a responsive grid layout with optional icons, dual labels, descriptions, and clickable cards. Supports 1-3 statistics per row; larger sets auto-fit in one row.

## Default

<Canvas of={StatsCardStories.Default} />

The default story shows three statistics with dual labels (top and bottom).

### Mixed content and sibling heights

Cards stretch to tallest sibling; on narrow screens, stacked cards retain natural height. Text length and optional content vary; resize to test RTL.

## Component props

### StatsCard

| Prop        | Type   | Default     | Description                                                                |
| ----------- | ------ | ----------- | -------------------------------------------------------------------------- |
| `title`     | string | -           | Optional heading for the stats section                                     |
| `stats`     | array  | `[]`        | Array of stat objects (see below)                                          |
| `variant`   | string | `'default'` | Visual variant: `'default'`, `'compact'`, `'highlighted'`, or `'negative'` |
| `className` | string | -           | Additional CSS class names                                                 |

### Stat object

| Prop          | Type          | Required | Description                                            |
| ------------- | ------------- | -------- | ------------------------------------------------------ |
| `value`       | string/number | Yes      | The main statistic value (e.g., "1,500+", "45%")       |
| `bottomLabel` | string        | No       | Label that appears below the value                     |
| `label`       | string        | No       | Optional label above the value                         |
| `icon`        | string        | No       | Optional icon class (e.g., "mg-icon fa-globe")         |
| `summaryText` | string        | No       | Optional descriptive text (supports inline HTML links) |
| `link`        | string        | No       | URL to make the entire stat card clickable             |

## Usage

```jsx
<StatsCard
  title="Sendai Framework Progress"
  stats={[
    {
      label: 'Target A',
      value: '45%',
      bottomLabel: 'Mortality reduction',
      summaryText: 'Decrease in disaster mortality rates.',
    },
    {
      label: 'Target B',
      value: '2.3M',
      bottomLabel: 'People affected',
      summaryText: 'Reduction in affected people per 100,000.',
    },
  ]}
/>
```

### Linked stats

```jsx
<StatsCard
  stats={[
    {
      value: '1,500+',
      bottomLabel: 'Cities enrolled',
      summaryText: 'Click to view all cities.',
      link: 'https://mcr2030.undrr.org/cities',
    },
  ]}
/>
```

## Accessibility

- Semantic HTML with `<section>`, `<article>`, and `<data>` elements
- Proper `aria-label` on the section
- Icons marked with `aria-hidden="true"`
- Focus-visible styles for keyboard navigation
- Respects `prefers-reduced-motion`

## Server-rendered / CDN usage

StatsCard supports [layered hydration](https://github.com/unisdr/undrr-mangrove/blob/main/docs/HYDRATION.md). Use data attributes on a container element:

```html
<div
  data-mg-stats-card
  data-title="Sendai Framework Progress"
  data-stats='[{"value":"45%","label":"Target A","bottomLabel":"Mortality reduction"}]'
  data-variant="default"
></div>
```

| Attribute         | Default     | Description                                                |
| ----------------- | ----------- | ---------------------------------------------------------- |
| `data-stats`      | `[]`        | JSON array of stat objects (required)                      |
| `data-title`      | —           | Optional heading for the stats section                     |
| `data-variant`    | `'default'` | `'default'`, `'compact'`, `'highlighted'`, or `'negative'` |
| `data-class-name` | `''`        | Additional CSS class names                                 |

```js
import createHydrator from 'https://assets.undrr.org/mangrove/2.0.0-beta.1/components/hydrate.js';
import StatsCard, {
  fromElement,
} from 'https://assets.undrr.org/mangrove/2.0.0-beta.1/components/StatsCard.js';
createHydrator({
  selector: '[data-mg-stats-card]',
  component: StatsCard,
  fromElement,
});
```

See the [hydration guide](https://github.com/unisdr/undrr-mangrove/blob/main/docs/HYDRATION.md) for the full API and integration details.
