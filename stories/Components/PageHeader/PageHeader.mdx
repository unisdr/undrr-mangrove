# Page header

PageHeader provides UNDRR top-of-page branding: logo, account/language controls,
and the four-color stripe. It can also render stripe-only mode.

### Overview

PageHeader includes:

- A dark toolbar section with UNDRR logo and language switcher
- Responsive design that adapts to different screen sizes
- The signature four-colored decorative stripe
- Option to render only the decoration stripe for lightweight branding

#### When to use:

- Use at the top of UNDRR pages for consistent branding and language switching.
- Use decoration-only mode when only the stripe is needed.

#### With Language Links

`languageDisplay="links"` shows each language inline in the toolbar instead of behind the icon-only dropdown. Use it for short lists (roughly 2-4 languages); for longer lists, keep `languageDisplay="dropdown"` (default). The active language is bold, and on smaller screens labels collapse to 2-letter codes. This mode requires JavaScript because the buttons drive the same underlying native `<select>` rather than linking to per-language URLs.

### Content

PageHeader content areas:

**UNDRR Logo Section:**

- Official UNDRR horizontal logo linked to homepage (configurable)
- Responsive crop behavior across breakpoints

**Language Switcher:**

- Icon-only trigger with real overlaid native `<select>` for browser-native
  dropdown behavior (English/Spanish/Arabic by default)
- Preserves Drupal form structure and processing attributes

**Visual Decoration:**

- Four brand stripes: red, purple, orange, and teal

> **Implementation note (for contributors):** The stripe colors map to SCSS variables `$sendai-red-900`, `$sendai-purple-900`, `$sendai-orange-900`, and `$sendai-turquoise-900` in `_variables.scss`.

### Behaviors

#### States

- **Logo** links to homepage in default variant.
- **Language switcher** opens native dropdown in default variant.
- **Responsive behavior:** logo crops at ≤1164px and ≤900px; account/language
  controls stay icon-only.
- **Decoration-only** renders stripe when `variant="decoration-only"`.

#### Google Analytics integration

The toolbar wrapper sets `data-vf-google-analytics-region="undrr-black-bar"` for analytics tracking.

> **Implementation note (for contributors):** The toolbar wrapper includes `data-vf-google-analytics-region="undrr-black-bar"` and all original Drupal data attributes for analytics and form processing. See [Integration Notes](#integration-notes) below for the full attribute list.

### Usage

#### React applications

React usage:

   ```jsx
   import { PageHeader } from './path/to/PageHeader';
   ```

Basic:

   ```jsx
   <PageHeader />
   ```

Decoration-only:

   ```jsx
   <PageHeader variant="decoration-only" />
   ```

Custom configuration:

   ```jsx
   <PageHeader
     logoUrl="https://assets.undrr.org/logos/undrr/undrr-logo-horizontal.svg"
     logoAlt="UNDRR Logo"
     homeUrl="https://www.undrr.org"
     languages={[
       { value: 'en', label: 'English', selected: true },
       { value: 'es', label: 'Español' },
       { value: 'fr', label: 'Français' },
     ]}
   />
   ```

Stripe-only toolbar context (no logo/account/language):
   ```jsx
   <PageHeader showLogo={false} showAccount={false} showLanguage={false} />
   ```

### Accessibility

The PageHeader component follows accessibility best practices:

- Uses semantic `<header>` element for proper document structure (default variant)
- Uses `<div>` element for decoration-only variant as it's purely decorative
- Includes proper `<section>` elements for each functional area
- Language switcher has proper form labeling with `sr-only` class for screen readers
- Account and language controls are icon-only visually, but keep accessible names via `mg-u-sr-only` text (not `title` attributes alone)
- The language control's visible focus ring is applied on the icon via `:focus-within` while the native `<select>` remains visually hidden
- Logo image includes proper alt text and title attributes
- Maintains keyboard navigation for all interactive elements
- Color contrast meets WCAG AA standards

### Props

| Prop         | Type    | Default                                                          | Description                                                                                                                                                                                                         |
| ------------ | ------- | ---------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| variant      | String  | 'default'                                                        | Component variant ('default' for full header, 'decoration-only' for stripe only)                                                                                                                                    |
| className    | String  | undefined                                                        | Additional CSS classes to apply                                                                                                                                                                                     |
| idPrefix     | String  | ''                                                               | Namespace for the header's element ids (`header`, `block-undrrlogo`, `edit-lang-dropdown-select`, ...). Ids are emitted verbatim by default; set a distinct prefix on each header when a page renders more than one |
| logoUrl      | String  | 'https://assets.undrr.org/logos/undrr/undrr-logo-horizontal.svg' | URL for the UNDRR logo image (ignored in decoration-only variant)                                                                                                                                                   |
| logoAlt      | String  | 'UNDRR Logo'                                                     | Alt text for the logo image (ignored in decoration-only variant)                                                                                                                                                    |
| logoTitle    | String  | 'UNDRR Logo'                                                     | Title attribute for the logo image (ignored in decoration-only variant)                                                                                                                                             |
| homeUrl      | String  | '/'                                                              | URL for the logo link (ignored in decoration-only variant)                                                                                                                                                          |
| showLogo     | Boolean | true                                                             | Show or hide the UNDRR logo section                                                                                                                                                                                 |
| showAccount  | Boolean | true                                                             | Show or hide the "My account" link                                                                                                                                                                                  |
| showLanguage | Boolean | true                                                             | Show or hide the language switcher                                                                                                                                                                                  |
| languageDisplay | String | 'dropdown'                                                    | 'dropdown' (icon-only, opens a native `<select>`) or 'links' (each language inline as its own button — best for 2-4 languages, requires JavaScript)                                                                |
| languages    | Array   | [English, Spanish, Arabic]                                       | Array of language objects (ignored in decoration-only variant)                                                                                                                                                      |
| ...args      | Object  | {}                                                               | Additional props passed to the root element                                                                                                                                                                         |

### Integration Notes

**Drupal integration:** preserves Drupal class names, attributes, and form
structure.
