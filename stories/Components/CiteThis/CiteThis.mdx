# Cite this

Cite this shows a page's citation on article, terminology, HIP and publication detail pages. Like ShareButtons, it has a label and a field to copy from, plus **All citation options**, which opens a dialog with the full citation, its URL and reference manager downloads. The publishing site decides where to show it; Mangrove formats available data and provides copying.

## Vanilla HTML page fallback

Drop the single HTML element shown below into a page and load `js/cite-this.js`. With no citation fields, the script uses the page's title, site name and canonical URL. It includes the access date because no publication year is known. In Storybook, the result cites Storybook's preview iframe; on a site, it cites that page.

## Citation source

The component uses the first available source:

1. An editorially supplied citation (`data-mg-cite-this-citation`). Mangrove displays and copies it unchanged.
2. Configured fields on the element (`data-mg-cite-this-title`, `-author`, `-publisher`, `-year`, `-url`, `-site`). These take precedence over matching structured data.
3. A `CreativeWork`, `Article`, `ScholarlyArticle`, `Book`, `Chapter`, `Report`, `NewsArticle`, `TechArticle` or `WebPage` JSON-LD entity whose URL, ID or `mainEntityOfPage` matches the page's canonical URL. A work nested as that `WebPage`'s `mainEntity` also qualifies.
4. Page title, site name and canonical URL. If no publication year is known, the citation states the access date rather than inventing a publication date.

Generated citations follow a simple UN website-materials form: creator and year where known, quoted title, publisher, and URL. The page fallback includes an access date. **The consuming site's editors should review this template before presenting generated text as an approved publication citation.** Published works with an official suggested citation should supply that text explicitly.

The page's URL is a locator. A publication citation describes the publication, and a HIP citation should identify its profile and edition. Schema.org's `citation` field lists works referenced _by_ a work; it is not read as that work's recommended citation.

An authored canonical link or configured citation URL keeps its query string, because it may identify the work. When no canonical link exists, the browser URL's query string is omitted from the page fallback. Analytics events omit query strings even when the citation itself includes one.

## Vanilla HTML

The shortest integration is `<div class="mg-cite-this" data-mg-cite-this></div>` plus the module script. If JavaScript is unavailable, that empty marker has no visible citation. To keep a citation readable without JavaScript, render the full HTML on the server, including citation text when it is known. JavaScript replaces the disclosure with the label, citation field, options link and native dialog (or, in the compact variant, a single button), resolves the citation, adds copy behavior, and emits events. The copy button is hidden until the script starts. In a browser without `<dialog>` support, the script keeps the disclosure and shows its copy button.

```html
<div
  class="mg-cite-this"
  data-mg-cite-this
  data-mg-cite-this-title="Response"
  data-mg-cite-this-author="United Nations Office for Disaster Risk Reduction"
  data-mg-cite-this-year="2017"
  data-mg-cite-this-publisher="UNDRR"
>
  <details class="mg-cite-this__fallback">
    <summary class="mg-cite-this__summary">Cite this</summary>
    <div class="mg-cite-this__content">
      <p class="mg-cite-this__text" data-mg-cite-this-text>
        United Nations Office for Disaster Risk Reduction (2017), “Response”,
        UNDRR, https://www.undrr.org/terminology/response.
      </p>
      <div class="mg-cite-this__actions">
        <button
          type="button"
          class="mg-cite-this__copy"
          data-mg-cite-this-copy
          hidden
        >
          Copy citation
        </button>
        <span
          class="mg-cite-this__status"
          data-mg-cite-this-status
          role="status"
          aria-live="polite"
        ></span>
      </div>
    </div>
  </details>
</div>
<script
  type="module"
  src="https://assets.undrr.org/mangrove/2.0.1/js/cite-this.js"
></script>
```

For Drupal behaviors or client-side navigation, call `mgCiteThis(context)` after insertion and `mgCiteThisDestroy(context)` before removal. Initialisation is idempotent and also runs on page load. The published module is `@undrr/undrr-mangrove/js/cite-this.js`.

Interface text has built-in translations; see [Languages](#languages). The citation is set in the body typeface inside a tinted box, with its title in quotation marks, and remains selectable. URLs in the citation, including those in an editorial citation, become links; the copied text is the same plain text as the rendered citation. Earlier markup put `mg-code` on the citation element; the component now overrides it, so existing markup does not need to change.

## Copy citation URL and reference manager export

Below the Copy citation button, the dialog offers:

- **Copy citation URL**, which copies the citation's URL: the configured URL, a matching Schema.org work's URL, or the canonical page URL. It is not the shortlink that ShareButtons copies, because a citation needs a lasting locator. Set `data-mg-cite-this-copy-url="false"` to remove it.
- **Download RIS** (for EndNote, Zotero and Mendeley) and **Download BibTeX** links. Both are on by default. Set `data-mg-cite-this-export` to `ris` or `bibtex` to offer one (a list sets the order), or to `none` to remove them.

<Canvas of={CiteThisStories.CitationOnly} />

The files are generated in the browser from the same fields as the citation: creators, title, publisher, year, URL and access date. Set `data-mg-cite-this-type` to `report`, `book` or `webpage` to choose the record type. Otherwise a matching Schema.org `Report` or `Book` sets it, and anything else is exported as a web page. Creators from configured fields, and Schema.org organisations, are exported as single corporate names. A Schema.org `Person` with `familyName` and `givenName` is exported as "Family, Given". An editorial citation is offered for export only when configured fields are also supplied, because its wording cannot be parsed back into fields.

## Languages

Cite this reads the `lang` attribute of its nearest ancestor, or of the document, and uses built-in text for Arabic, Chinese, English, French, Japanese, Russian and Spanish. Region subtags are ignored, so `fr-CA` uses French. Any other language falls back to English. Use the Locale toolbar to preview each one.

The same language sets the conventions of an automatic citation: the access date ("consulté le 25 septembre 2026", always with Western digits, as in UN documents), the title quotation marks (« » in French, «» in Russian, 《》 in Chinese, “ ” otherwise) and the separators (the Arabic comma in Arabic). The title and URLs are isolated so that a Latin title or URL keeps the punctuation in place on right-to-left pages; the copied text is plain. An editorial citation is shown exactly as written.

With full server markup, the summary and copy button text come from the markup, so render them in the page language. Any string can be overridden with a data attribute, for another language or for house style:

| Attribute                            | Default (English)                                                 |
| ------------------------------------ | ----------------------------------------------------------------- |
| `data-mg-cite-this-label`            | Cite this (empty marker only; otherwise the summary text)         |
| `data-mg-cite-this-copy-label`       | Copy citation                                                     |
| `data-mg-cite-this-copied-label`     | Citation copied                                                   |
| `data-mg-cite-this-failed-label`     | Copy failed. Select the citation and copy it manually.            |
| `data-mg-cite-this-copy-url-label`   | Copy citation URL                                                 |
| `data-mg-cite-this-url-copied-label` | URL copied                                                        |
| `data-mg-cite-this-url-failed-label` | Copy failed. Select the URL in the citation and copy it manually. |
| `data-mg-cite-this-close-label`      | Close                                                             |
| `data-mg-cite-this-more-label`       | All citation options                                              |
| `data-mg-cite-this-ris-label`        | Download RIS                                                      |
| `data-mg-cite-this-bibtex-label`     | Download BibTeX                                                   |

JavaScript hosts, such as React wrappers or these stories, can read the built-in table with `citeThisStrings(lang)` to render the fallback in the same words.

## Analytics

The element dispatches bubbling events:

| Event                     | When                                                           |
| ------------------------- | -------------------------------------------------------------- |
| `mg-cite-this:open`       | The dialog opens.                                              |
| `mg-cite-this:copy`       | The citation is copied.                                        |
| `mg-cite-this:copy-url`   | Copy citation URL succeeds.                                    |
| `mg-cite-this:copy-error` | A copy fails. `detail.target` is `citation` or `url`.          |
| `mg-cite-this:export`     | A download link is used. `detail.format` is `ris` or `bibtex`. |
| `mg-cite-this:visit`      | A link inside the dialog's citation is followed.               |

Every event's `detail` has:

- `id`: a stable key for the cited work, for counting one work across the pages that cite it. It is `data-mg-cite-this-id` when set, otherwise the matching Schema.org work's `identifier` (such as a DOI or ISBN), then its `@id` when that is not just the page or work URL with a fragment, and only as a last resort the work's URL. **Set `data-mg-cite-this-id`** to something that never changes and is unique across UNDRR sites: a DOI where there is one, otherwise the site and node, such as `preventionweb:node/12345`. A bare node ID is not enough, because each site numbers its nodes separately.
- `pageUrl`: the query-free canonical URL of the page where the action happened.
- `url`: the cited work's query-free URL, which can change when the work is edited.
- `source`: where the citation came from (`provided`, `metadata`, `schema` or `page`).
- `layout`: `default`, `compact`, or `disclosure` when the browser has no `<dialog>` support.
- `placement` on copy, copy error, export and visit events: `field` for the citation field, `dialog` for the dialog, or `disclosure`.

To see how often a given publication is cited on given pages, group by `id` and `pageUrl`. The consuming site maps these events to GA4 through its consent-aware analytics setup. Mangrove itself sends nothing to Google.

```js
document.addEventListener('mg-cite-this:copy', event => {
  analytics.track('citation_copy', {
    work_id: event.detail.id,
    page_url: event.detail.pageUrl,
    citation_source: event.detail.source,
    placement: event.detail.placement,
  });
});
```

### UNDRR click tracking

UNDRR sites also load a shared GA4 click tracker, which names each click after the element's visible text unless `data-vf-analytics-label` is set. Like ShareButtons, Cite this sets fixed English labels so reports do not split by citation text or language: `Cite this: Copy citation (field)`, `Cite this: All citation options`, `Cite this: Open` (compact), `Cite this: Copy citation (dialog)`, `Cite this: Copy citation URL`, `Cite this: Download RIS`, `Cite this: Download BibTeX`, `Cite this: Citation link` and `Cite this: Close`. The element gets `data-vf-google-analytics-region="cite-this"` unless the host has set its own region. These click events count attempts, not successful copies, and carry no work `id`; for per-publication reporting, map the events above to GA4 as well.

## Accessibility

Once enhanced, the element is a group named by its "Cite this" label. The citation field is a button whose accessible name is "Copy citation:" followed by the citation, so the visible text is part of its name. It shows the citation clamped to two lines, and the full text is in the dialog. If copying from the field fails, the dialog opens so the citation can be selected there. **All citation options** (or the compact Cite this button) opens a native modal dialog. Focus moves to its title, stays in the dialog while it is open, and returns to the button that opened it when closed with Escape or the named close icon button. The close control uses Mangrove's shared `mg-icon-button` and `mg-icon-close` styles. Without JavaScript, native `details` and `summary` provide disclosure keyboard behavior. The copy buttons appear only when the JavaScript enhancement is active. Copy success and failure are announced in a polite live region. The citation is always selectable text.
