# Form action

Joins one field to one high-priority action as a continuous control. The input and button remain separate semantic elements with independent focus states.

## When to use

- Search, subscribe, apply, check, redeem or compact submission flows.
- When the action operates only on the immediately adjacent field.
- When joining the controls makes the relationship faster to understand.

Do not use it for two unrelated actions, destructive actions, multi-step forms, or several fields sharing one submit button. Use a normal form layout and `.mg-buttons` instead.

## Usage

```jsx
<FormAction
  label="Email address"
  helpText="We will send a confirmation email."
  control={
    <input
      className="mg-form-input"
      type="email"
      placeholder="name@example.org"
    />
  }
  action={
    <button className="mg-button mg-button-primary" type="submit">
      Subscribe
    </button>
  }
/>
```

For vanilla HTML, apply `.mg-form-action` to the joined row, `.mg-form-action__control` to its field, and `.mg-form-action__action` to its button.

## Accessibility

- The generated field ID connects the visible or visually hidden label to the control.
- Help and error messages are composed with an existing `aria-describedby` value.
- Error text sets `aria-invalid` and uses `role="alert"`.
- The field and action retain separate focus rings and keyboard stops.
- Both controls retain at least a 44px interaction target.
