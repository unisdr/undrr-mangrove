# Checkbox

A checkbox input for selecting one or more options.

## Overview

The checkbox component lets users select or deselect individual options. Each checkbox operates independently and can be grouped inside a `<fieldset>`.

## When to use

- When the user can select zero, one, or multiple options from a set.
- For binary choices like accepting terms or toggling a preference.

## States

- **Default**: Unchecked, red border.
- **Checked**: Red fill with checkmark.
- **Hover**: Purple border on hover.
- **Focus**: Blue outline on keyboard focus.
- **Disabled**: Grey border, non-interactive.

## Switch toggle (`.mg-switch`)

For immediate binary state switches (e.g., activating map layers, live filtering, feature toggles) where a standard form checkbox reads as an unanswered form field, use `.mg-switch` with `role="switch"`.

<Canvas of={CheckboxStories.Switch} />

```html
<label class="mg-switch">
  <input type="checkbox" role="switch" class="mg-switch__input" />
  <span class="mg-switch__track" aria-hidden="true">
    <span class="mg-switch__thumb"></span>
  </span>
  <span class="mg-switch__label">Active map layer</span>
</label>
```

Disabled state (use the HTML `disabled` attribute, not CSS-only styling):

<Canvas of={CheckboxStories.SwitchDisabled} />

```html
<label class="mg-switch">
  <input type="checkbox" role="switch" class="mg-switch__input" disabled />
  <span class="mg-switch__track" aria-hidden="true">
    <span class="mg-switch__thumb"></span>
  </span>
  <span class="mg-switch__label">Unavailable layer</span>
</label>
```

> **Note:** The native `<input type="checkbox">` manages the checked/unchecked state for assistive technologies automatically. When toggling the switch via JavaScript, update the `checked` property on the input element rather than managing `aria-checked` separately.

## Accessibility

- The label is programmatically associated with the checkbox via `htmlFor`/`id`.
- For groups of checkboxes, wrap them in a `<FormGroup>` (renders `<fieldset>` with `<legend>`).
- Keyboard users can toggle the checkbox with Space.
