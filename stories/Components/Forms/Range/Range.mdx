# Range

The Range component allows users to select a value or range of values from a defined set. It is styled to fit within the UNDRR Mangrove Design System, supporting continuous and discrete (stepped) options.

## Analytics

The shared click tracker on UNDRR sites names a click on the slider after its `name`. Set `analyticsLabel` to give the input a fixed `data-vf-analytics-label` instead. A `data-vf-analytics-label` passed directly still wins.

## Prototype notice

This component is a prototype and subject to change. The API and behavior may be updated based on user feedback and usability testing.
