# Aria ComboBox

A React-only searchable choice control. It uses React Aria for interaction and Mangrove tokens and classes for presentation. Import `aria/combo-box.css` with a normal Mangrove theme stylesheet, or with one `aria/tokens/{brand}.css` file in a React-only application. The broad `aria/react-aria.css` skin is not required.

## When to use

Use this for a searchable list or custom text values in a React application. Use the native [Select](?path=/docs/components-forms-select--docs) for an ordinary fixed choice list.

## Behaviour and accessibility

Pass items as `{ id, label }` objects. The label and suggestion button text are supplied by the caller so they can be translated. React Aria handles filtering, keyboard navigation, selection, required state and form value. Pass `inputValue` with `onInputChange` for a controlled input; pass `selectedKey` with `onSelectionChange` for controlled selection.

React Aria portals the suggestion list. If the theme is scoped to a wrapper rather than `<body>`, pass that wrapper element as `popoverContainer` so the list inherits its tokens. This prop maps to React Aria's `UNSTABLE_portalContainer` and should be rechecked on library upgrades.

## CSS and JavaScript

- Styles: `aria/combo-box.css` (opt-in), sourced from `stories/assets/scss/aria/_combo-box.scss`.
- JavaScript: `components/AriaComboBox.js` in the assembled npm package. React is external; the React Aria behaviour is bundled with this optional entry.
- Theme values: `--mg-control-*` roles and existing Mangrove form, focus, spacing and typography tokens. The component never relies on `.react-aria-*` class names.

Tailwind 4 puts utilities in a cascade layer. To let those utilities override the pilot's CSS, declare the order before either import and place the optional stylesheet in the earlier layer:

```css
@layer theme, base, mg-components, components, utilities;
@import '@undrr/undrr-mangrove/css/style.css';
@import '@undrr/undrr-mangrove/aria/combo-box.css' layer(mg-components);
```

Replace `css/style.css` with the chosen theme, or one standalone `aria/tokens/{brand}.css` file. Existing unlayered application CSS has higher priority than layered styles; test the import order in the consuming application.
