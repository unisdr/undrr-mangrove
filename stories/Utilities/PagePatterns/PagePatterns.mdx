# Reading column

A reading-column utility with an optional sticky contents sidebar, used by
[content hub](?path=/docs/patterns-content-hub--docs) and
[landing page](?path=/docs/patterns-landing-pages--docs).

This is a class (not a component); use the markup directly.

## Reading column

<Canvas of={Stories.ReadingColumn} />

```html
<div class="mg-reading mg-reading--with-contents mg-grid mg-grid--article">
  <div><!-- contents --></div>
  <div class="mg-reading__article">…</div>
</div>
```

Constrains the article to a readable measure. With `--with-contents`, the first
child becomes a sticky right sidebar from 48rem upward and stacks above the
article below that width. Pair `mg-reading--with-contents` with
`mg-grid mg-grid--article` to get the sidebar column split
(see [Grid layout](?path=/docs/design-decisions-grid-layout--docs)).
