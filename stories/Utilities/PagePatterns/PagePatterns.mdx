# Page composition

CSS classes for assembling a full page: a reading column with an optional sticky
contents sidebar, and a grid of short icon facts. For a full-width tinted band,
combine `mg-container-full-width` with a background utility.
Used by the [content hub](?path=/docs/patterns-content-hub--docs) and
[landing page](?path=/docs/patterns-landing-pages--docs) patterns.

These are classes, not components. The React wrappers in this story exist only
so the classes can be seen; use the markup directly.

## Reading column

<Canvas of={Stories.ReadingColumn} />

```html
<div class="mg-reading mg-reading--with-contents">
  <div><!-- contents --></div>
  <div class="mg-reading__article">…</div>
</div>
```

Constrains the article to a readable measure. With `--with-contents` the first
child becomes a sticky right sidebar from 48rem up and stacks above the article
below that.

## Facts

<Canvas of={Stories.FactsGrid} />

```html
<ul class="mg-facts">
  <li>
    <span class="mg-icon mg-icon-globe" aria-hidden="true"></span>
    A short fact
  </li>
</ul>
```

A responsive grid of short icon-and-label facts, for the supporting band on a
landing page. Icons are decorative and carry `aria-hidden`; the label is the
content.
