Source edits → portable tokens → a plain HTML application

These pages use the exported token data with native HTML controls and their own small stylesheet. They load no React code or Mangrove component stylesheet.

The right-hand example comes from three edits to a temporary copy of the actual token source, followed by the normal exchange build: the accent becomes purple, medium font weight changes from 500 to 700, and compact spacing changes from 12px to 16px. The repository’s token sources remain unchanged.

Reproduce it

From the Mangrove checkout: node scripts/create-delta-token-consumer.mjs, then node scripts/serve-storybook.mjs .cache/token-only-consumer 6105. Open http://127.0.0.1:6105/. To copy this consumer elsewhere, copy this output folder; the browser only needs the HTML, small CSS/JavaScript, exported JSON and bundled licensed fonts.
