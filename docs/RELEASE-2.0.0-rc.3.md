# Mangrove 2.0.0-rc.3

Mangrove 2.0.0-rc.3 is the final planned polishing release before stable 2.0, bringing accessibility, typography, responsive layout and integration fixes. We expect stable 2.0 shortly, subject to final integration testing.

See the [complete 2.0 release notes](https://mangrove.undrr.org/?path=/docs/getting-started-release-notes-v2-0--docs) for the full overview and upgrade guidance.

This is a prerelease for the npm `next` tag; `latest` remains on 1.x.
